# yao-geo-intent-miner（适配版）

配套：`seo-agent/workflows/intent-research.md`（流程编排）、`seo-agent/references/geo-citability.md` §5（国内平台适配）、`seo-agent/references/google-currency.md` §3。

## 使用场景

- 把种子词、品牌、产品线、竞品、区域、人群和业务材料扩展成 AI 搜索问题集
- 先于内容生产建立问题底座：意图簇、追问链路、查询重写、内容选题、FAQ、知识库、监测 Prompt
- 面向 DeepSeek、豆包、千问、Kimi、元宝适配口语、多轮、场景、复杂决策问法

## 执行流程

1. **归一化输入**：主对象、品牌、产品线、行业、竞品、区域、人群、预算、场景、痛点、资质、规模、时效、材料来源
2. **判断数据模式**：`未接入 / 用户提供 / 工具或连接器导入 / 已采样校准`；没有真实数据时输出数据缺口与采样计划，**不伪造**平台回答、搜索量、转化数据
3. **事实与证据校准**：品牌/产品/价格/合规/竞品/行业事实标注来源状态；未校准信息只能作为假设或待确认项
4. **双层意图**：先映射任务层（信息/导航·验证/交易·行动），再扩展九类 GEO 操作意图（信息/推荐/比较/交易/风险/价格/替代/场景/品牌验证）
5. **问题生成**：按角色、场景、决策阶段、约束、证据需求、资产用途生成**完整自然语言问题**（不能只堆短关键词）
6. **五段式重写**：`user_question`（口语问法）、`standalone_rewrite`（独立重写）、`retrieval_rewrite`（检索短语）、`evidence_query`（证据检索式）、`title_seed`（标题输入）
7. **追问链路**：保留 `root_question_id / parent_question_id / follow_up_level / context_dependency / standalone_rewrite / platform_fit / sample_prompt`；Kimi/千问保留可回放链路；豆包/元宝侧重口语转写；DeepSeek 增加约束与权衡
8. **聚类去重**：按目标/角色/约束/资产用途/合规合并同义；保留语义不同的问题；同义合并保留更口语、更具体、更易触发 AI 答案的作为展示问题；竞品问题中性表达
9. **十维评分**（1-5；合规风险反向）：商业价值 15%、AI 答案触发概率 12%、内容缺口 12%、品牌植入空间 12%、证据可得性 10%、竞争难度 8%、对话延展价值 8%、决策阶段价值 10%、平台覆盖度 8%、合规风险 5%；有真实数据时按搜索量/采样/客服频次/转化信号校准
10. **资产映射**：文章 / 页面模块 / FAQ / 知识库条目 / 监测 Prompt / 标题生成输入包 / 证据补采任务 / 30-60-90 天路线
11. **优先级**：P0 = 总分高 + 证据可得 + 品牌可自然植入 + 可映射页面/内容；P1 = 有内容价值但证据/竞争/合规需补；P2 = 长尾或仅监测

## 输出契约

- AI 搜索问题集与意图地图
- 问题聚类、追问链路、查询重写清单
- 评分矩阵与优先级排序
- 内容选题、FAQ 题库、知识库条目建议
- 监测 Prompt 库（可直接交 `workflows/ai-visibility.md`）
- 证据缺口、合规边界、落地路线
- 真实数据接入状态与采样计划

## 边界

- 不伪造平台回答、搜索量、转化数据
- 竞品中性表达，不输出无法证实的负面判断
- 无真实数据时区分「假设」与「已校准」，标注数据缺口
