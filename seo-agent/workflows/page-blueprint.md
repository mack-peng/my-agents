# ③ 页面目的适配（page-blueprint）

**这条工作流是什么**：按用户给的**页面目的**（首页/产品页/文章页/FAQ/落地页/对比页/文档页…）产出 GEO 友好的页面设计方案：信息架构、AI 可抽取模块、HTML 语义、Schema 选型、元信息模式、内链与转化模块、前端/CMS 字段清单。

**分几步**：6 步（目的确认 → 输入与边界 → Query fan-out → 架构与模块设计 → 技术层设计 → 交付）

**每步做什么**：见下文。方法底稿在 `.agents/skills/yao-geo-page-blueprint/SKILL.md`（移植版）与 `references/schema-by-page-purpose.md`。

**哪几步停下来等你**：目的/边界确认（信息不足时）、方案交付后 sign-off。中途不打断。

---

## 输入

| 项 | 必需 | 说明 |
|----|------|------|
| 页面目的 | ✅ | 首页/产品页/文章页/FAQ/对比页/落地页/文档页/案例页… |
| 品牌与产品事实 | ✅ | 官方素材：产品名、定位、价格事实、服务边界、资质（不得编造） |
| 参考页面 | 可选 | 现有 URL（做诊断型蓝图）或竞品页 |
| 目标平台 | 建议 | Google / 百度 / 国内 AI 平台（DeepSeek/豆包/千问/Kimi/元宝） |

**无真实素材时**：所有推断内容标「方案假设」，输出"待核实清单"；不得把模型记忆写成品牌事实。

## 步骤

### 1. 页面目的确认

- 归一化页面目的与用户路径：目标问题是什么？谁来读？转化动作是什么？
- 目的不清晰 → 最多问 2 个问题；可推断则推断后声明

### 2. 输入、假设与边界

- 建表：已知事实（来源）/ 设计假设 / 数据缺口 / 合规限制 / 待确认项
- 事实来源分级：官方素材 > 客户提供 > 第三方资料 > 方案假设（引用 `geo-citability.md` §4 证据标记）

### 3. Query fan-out（问题族覆盖）

- 主问题 → 子问题矩阵：定义/对比/风险/价格/替代方案/实施/案例/FAQ/转化
- 每个子问题映射到页面模块与答案形态（段落/表格/列表/步骤/问答）
- 国内平台问法适配（`geo-citability.md` §5）：哪家好/怎么选/多少钱/适合谁…

### 4. 信息架构与模块设计

按 `yao-geo-page-blueprint` 移植方法输出：

1. 首屏直接答案（普通文本，结论前置）
2. 结构化摘要（页面顶部/结尾各一段可独立理解）
3. 核心事实卡（`<dl>`/表格，原子事实）
4. 判断框架（怎么选/适用边界）
5. 对比表（同口径，表前声明口径）
6. 实体关系（品牌/产品/场景/竞品，`@id` 建议）
7. 证据区与来源台账（来源名/URL/核验日期/用途）
8. AI 可抽取模块（键值对/步骤/Q&A/原子事实）
9. FAQ（高价值问题中前段放置，不全部堆底部）
10. 案例/证明
11. 转化模块（CTA/表单，不干扰答案与证据区）
12. 结尾摘要

### 5. 技术层设计

- **HTML 语义样例**：`<main>`/`<article>`/`<table>`/`<dl>` 结构（对照 `schema-by-page-purpose.md` §3 契约）
- **Schema 选型与字段来源**：按目的选主类型+配套类型；字段 → 正文事实映射；排除废弃类型
- **元信息模式**：title 模式（品牌位置/长度）、description 模式、canonical、OG
- **前端/CMS 字段清单**：字段 key、中文名、类型、必填、来源、校验、前端位置、是否进 schema
- **无障碍与体验**：标题层级、键盘焦点、移动布局

### 6. 交付

- 按 `templates/page-blueprint.md` 输出到 `output/{YYYY-MM-DD}-{页面标识}-page-blueprint.md`
- **Sign-off**：交付后停下；确认后可衔接 ①（对现有页审查）或 ②（对现有项目出修改设计）

---

## 校验清单（交付前自检）

- [ ] 首屏不是纯营销口号：有直接答案 + 关键事实 + 摘要
- [ ] Query fan-out 覆盖主问题与合理子问题（定义/对比/风险/价格/替代）
- [ ] 每个模块说明"服务哪个子问题 + 答案形态"
- [ ] 事实与假设分离；无来源的事实不进正文
- [ ] FAQ 进入页面中前段，不在底部堆砌
- [ ] Schema 只描述正文已有事实；不编造评分/价格/资质/评价
- [ ] llms.txt 等无据技巧不出现（除非用户主动问，按 `google-currency.md` §3 口径回答）
- [ ] 证据区含来源、位置、核验日期、用途

## Hard Stop

- 无品牌素材时仍强行输出"事实" → 禁止；标假设或列入待核实
- 方案交付后停下，不自动改代码（衔接 ② 需用户确认）
