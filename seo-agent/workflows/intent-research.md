# ⑤ 关键词意图调研（intent-research）

**这条工作流是什么**：把种子词、品牌、产品、竞品、人群和业务材料扩展成「AI 搜索问题集 + 意图簇 + 追问链路 + 内容选题/FAQ/知识库条目 + 监测 Prompt 库」，供 ③ 页面蓝图与 ④ AI 可见性直接复用。

**分几步**：6 步（输入归一化 → 事实校准 → 意图生成 → 重写与聚类 → 评分与映射 → 交付）

**每步做什么**：见下文。方法底稿在 `.agents/skills/yao-geo-intent-miner/SKILL.md`（移植版）。

**哪几步停下来等你**：问题集范围确认（可能一次问 2 个问题）、报告交付后 sign-off。

| 项 | 必需 | 说明 |
|----|------|------|
| 种子词 | ✅ | 核心词/品牌/产品线/行业类目 |
| 业务材料 | 建议 | 竞品、区域、人群、预算档位、场景、痛点、资质、规模 |

## 步骤

### 1. 输入归一化

主对象（品牌/产品线/服务/功能/行业类目）、用户角色、场景、约束（预算/团队/地域/合规/语言）、疑虑、材料来源——建归一化表。

### 2. 事实与证据校准

- 品牌/产品/价格/合规/竞品/行业事实标注来源状态：`已核实 / 用户提供 / 假设 / 待确认`
- 未校准信息只能作为假设或待确认项；**不伪造搜索量、转化数据、平台回答**
- 数据模式声明：`未接入 / 用户提供 / 工具导入 / 已采样校准`

### 3. 意图生成

**双层意图**：
- 任务层：信息型 / 导航·验证型 / 交易·行动型
- GEO 操作层（九类）：信息型 / 推荐型 / 比较型 / 交易型 / 风险型 / 价格型 / 替代型 / 场景型 / 品牌验证型

**生成维度**：主对象 × 用户角色 × 场景 × 约束 × 疑虑 × 资产用途。
**输出必须是完整自然语言问题**（不能只堆短关键词）。

可选增强（用户有需求时）：用 browser-agent 采集搜索引擎/AI 平台联想词（截图留证，标注采集日期）；百度/Google 相关搜索亦可。

### 4. 五段式重写与追问链路

每条问题至少产出：

| 字段 | 说明 |
|------|------|
| `user_question` | 用户口语问法 |
| `standalone_rewrite` | 独立重写（去掉上下文指代） |
| `retrieval_rewrite` | 平台可能检索的短语/专业词 |
| `evidence_query` | 找案例/标准/价格/资质/数据的检索式 |
| `title_seed` | 标题与内容生产输入 |

追问链路（Kimi/千问等保留可回放）：`root_question_id / parent_question_id / follow_up_level / context_dependency / standalone_rewrite / platform_fit / sample_prompt`。

### 5. 聚类去重与评分映射

**聚类**：按问题目标/角色/约束/资产用途/合规合并同义；保留语义不同的问题；同义合并时保留更口语、更具体、更易触发 AI 答案的作为展示问题。竞品问题**中性表达**。

**十维评分**（1-5 分，`合规风险` 反向）：

| 维度 | 权重 |
|------|------|
| 商业价值 | 15% |
| AI 答案触发概率 | 12% |
| 内容缺口 | 12% |
| 品牌植入空间 | 12% |
| 证据可得性 | 10% |
| 决策阶段价值 | 10% |
| 竞争难度 | 8% |
| 对话延展价值 | 8% |
| 平台覆盖度 | 8% |
| 合规风险（反向） | 5% |

**优先级**：P0 = 总分高 + 证据可得 + 品牌可自然植入 + 可映射到页面/内容；P1 = 有内容价值但证据/竞争/合规需补；P2 = 长尾或仅监测。

**资产映射**：文章（完整解释/榜单/对比/风险）｜页面模块（交易意图/资质/案例/价格）｜FAQ（价格/适用对象/边界/售后）｜知识库（教程/概念/流程）｜监测 Prompt（→ ④）｜标题输入包｜证据补采任务｜30/60/90 天落地节奏。

### 6. 交付

- 按 `templates/intent-report.md` 输出到 `output/{YYYY-MM-DD}-{主题}-intent-research.md`
- **Sign-off**：交付后停下；提示可衔接 ④（问题集采样）或 ③（选题 → 页面蓝图）

---

## 输出约定

- 问题清单以表格/列表呈现，标注：意图类型、决策阶段、优先级、映射资产
- 监测 Prompt 单独成节（可直接复制到 ④ 的问题集文件）
- 数据缺口与采样计划单独成节（哪些分数需要真实数据校准）
- 不把短关键词堆砌当"关键词表"交付——问题优先，关键词作为附属

## Hard Stop

- 无真实数据时标注数据缺口，不伪造平台回答/搜索量/转化
- 报告交付后停下，不自动开始采样（④ 需用户确认）
