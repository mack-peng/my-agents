# 模板：SEO 审查报告

> 输出路径：`output/{YYYY-MM-DD}-{domain或项目}-seo-audit.md`
> 使用规则：表格 ≤5 列；来源用短链接文字；「未测」与「缺口」如实标注；每条发现必填四要素。
> 复审约定：交付后用户执行修复 → 在同一报告更新对应条目（原问题 → ✅ 已修复 + 验证证据）并同步执行摘要与评分，**不新建报告**。

- **页面目的**：{首页/产品页/文章页/…}
- **目标市场**：{Google / 百度 / AI 搜索}
- **审查日期**：{YYYY-MM-DD}
- **方法**：firecrawl 抓取 + {渲染对比 / 代码扫描}；评估口径见附录
- **时效基线**：Google 官方变更核对至 2026-10-09（seo-agent/references/google-currency.md）
