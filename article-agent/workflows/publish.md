# 工作流 ④ 发布

## 这条工作流是什么

终稿确认后：先问配图 → 落盘 → 飞书归档。

## 分几步

1. 配图（可选，终稿确认后询问）
2. 终稿落盘
3. 飞书归档（仅 USE_FEISHU=true）
4. 收尾提示

## 每步做什么

### 1. 配图（可选，终稿 sign-off 后第一步）

- 终稿确认后主动问一句：「要不要把配图也做了？（封面 + 内页，按配图建议）」
- 用户同意 → 按文章内容节点逐张生成**横版文章插画**，委托 `use aliyun-agent`：
  - 模型默认 `z-image-turbo`（快、少限流）；需要图中出现准确中文时用 `qwen-image-3.0`（慢，单张可能超 5 分钟，注意超时设置）
  - 尺寸 `16:9`（长方形），`--watermark false`；画面不出现文字（负面词：文字 / 字母 / 数字 / 水印）
  - **每张生成后必须读图自检**：有无乱码文字、构图是否符合内容；不合格改提示词重出
- 交付到 `output/{YYYYMMDD}-{slug}-配图/`，按顺序命名（`A-…` / `B-…` / …）
- **并穿插进终稿文档**：每张插到对应正文段落之后（先 append 再 `block_move_after` 移到锚点段后），带编号 caption 01…05，不要统一堆在文末
- 用户不需要 → 跳过

### 2. 终稿落盘

- 写入 `article-agent/output/{YYYYMMDD}-{slug}.md`（目录不存在先创建）
- 格式见 `templates/deliverable.md`：标题候选 / 封面文案 / 配图建议 / 长文正文 / 描述 / 标签 + @ / 发布备注

### 3. 飞书归档（仅飞书模式）

`use feishu-agent`：在 `FEISHU_WIKI_ID` 知识库创建**两篇文档**：

- **终稿**（**文档名 = 笔记标题**）：**正文 + 配图**（如有）——正文无任何标记行；配图**穿插在对应正文段落之后**（带编号 caption 01…），下载导出 Word 直接上传小红书
- **任务记录**（`{选题} · 任务记录`）：过程归档 + **发笔记用的标题 / 描述 / 标签** + 配图路径——发笔记时从这里复制

详见 `AGENTS.md`「飞书文档格式」。返回两篇文档链接给用户。

### 4. 收尾提示

- 告知本地文件路径、配图目录（及飞书链接，如有）
- 提示下一步：再写一篇 / 继续改 / 直接发布

## 哪几步停下来等你

- 📍 **配图**：终稿确认后先问，同意才做
- 📍 **落盘发布前**：必须已有终稿 sign-off
- 📍 **飞书归档前**：告知将上传到知识库，用户同意后执行
