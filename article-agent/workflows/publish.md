# 工作流 ④ 发布

## 这条工作流是什么

把确认过的终稿落盘，并在飞书模式下全过程归档。

## 分几步

1. 终稿落盘
2. 飞书归档（仅 USE_FEISHU=true）
3. 收尾提示

## 每步做什么

### 1. 终稿落盘

- 写入 `article-agent/output/{YYYYMMDD}-{slug}.md`（目录不存在先创建）
- 格式见 `templates/deliverable.md`：标题候选 / 封面文案 / 配图建议 / 长文正文 / 描述 / 标签 + @ / 发布备注

### 2. 飞书归档（仅飞书模式）

`use feishu-agent`：在 `FEISHU_WIKI_ID` 知识库创建**两篇文档**：

- **终稿**（**文档名 = 笔记标题**）：**只有长文正文**——无标题行、无分隔线、无描述/标签，下载导出 Word 直接上传小红书
- **任务记录**（`{选题} · 任务记录`）：过程归档 + **发笔记用的标题 / 描述 / 标签**——发笔记时从这里复制

详见 `AGENTS.md`「飞书文档格式」。返回两篇文档链接给用户。

### 3. 收尾提示

- 告知本地文件路径（及飞书链接，如有）
- 提示下一步：再写一篇 / 继续改 / 直接发布

## 哪几步停下来等你

- 📍 **发布前**：必须已有终稿 sign-off（未确认不落盘发布）
- 📍 **飞书归档前**：告知将上传到知识库，用户同意后执行
