# 工作流 ③ 改稿

## 这条工作流是什么

已有稿子，按用户意见定向修改。只改要求的部分，不重写、不夹带。

## 分几步

1. 定位现有稿
2. 明确修改点
3. 定向修改
4. 输出改动说明（📍结构性大改先停下确认）

## 每步做什么

### 1. 定位现有稿

- 优先取 `output/` 目录最新文件；用户指定文件或直接贴了内容则以指定为准
- 找不到稿子时向用户确认（哪个文件 / 直接贴过来）

### 2. 明确修改点

常见类型：

- **换语气**（严谨 / 专业 / 俏皮）→ 按 `references/tone-guide.md` 重写，保留事实与结构
- **改标题** → 给 3-5 个新候选（≤20 字）
- **调描述** → 保持约 100 字与四类引流要素
- **按意见改** → 逐条落实用户意见，不扩大范围

### 3. 定向修改

- 长文禁止 markdown 符号；引号统一「」
- 涉及事实/数据的新增内容：能核实才写，不能核实标注「待补」

### 4. 输出改动说明

- 列出「改了哪里、为什么」
- 若改动涉及结构与核心表达（不只是措辞）→ 先给方案，**停下等确认**再动手
- 纯措辞类改动 → 直接给新版本，用户可以继续提意见

## 哪几步停下来等你

- 📍 **结构性大改前**：先说方案再动手
- 📍 **改完**：给新版本，等用户确认或继续提意见
