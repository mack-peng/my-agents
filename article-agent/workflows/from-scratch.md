# 工作流 ② 从 0 创作（对话访谈）

## 这条工作流是什么

用户没有素材，从零开始。通过对话访谈不断获取上下文，逐步把内容聊出来，再加工成小红书笔记。

## 分几步

1. 起点访谈
2. 循环补料（每轮 1-2 问，简报逐步长大）
3. 调研补料（可选，委托 research-agent / browser-agent）
4. 创作简报（📍停下等你确认）
5. 成稿与自检
6. 终稿交付（📍停下等你确认）

## 每步做什么

### 1. 起点访谈

开场只问 1-2 个问题，优先问：

- 你是做什么的？这篇写给谁看？
- 这篇的目的：涨粉 / 引流 / 参加活动 / 记录？

把用户的回答先记进「创作简报（草稿）」。

### 2. 循环补料

- 每轮只问 1-2 个问题；问完把回答整理进「创作简报（草稿）」并展示给用户看（让用户看到简报在长大）
- 优先收集：具体的故事/场景/数字、从业经历、想表达的情绪、最想让读者记住的一句话
- 简报信息足够支撑成稿时，停止提问，进入下一步
- 用户中途改方向 → 更新简报，继续

### 3. 调研补料（可选）

- 判断是否存在事实缺口（政策、数据、行业信息、竞品情况）
- 向用户提议："这块我可以查一下——用 research-agent 调研，还是你直接给我资料？"
- 用户同意 → `use research-agent`（深度调研 / 简单搜索；指定网页用 `use browser-agent`）
- 只把**摘要**写进简报，全文不堆进对话

### 4. 创作简报（📍）

把草稿整理成正式简报：角度 / 读者 / 语气（含判断理由）/ 结构 / 素材来源 / 预计字数。

→ **停下等确认**。用户确认前不动笔。

### 5. 成稿与自检

同工作流 ① 第 4 步。

### 6. 终稿交付（📍）

同工作流 ① 第 5 步。

## 哪几步停下来等你

- 📍 **简报确认**：角度与结构 OK 才写正文
- 📍 **终稿确认**：全文 OK 才发布
