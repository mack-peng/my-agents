# 工作流 ① 内容加工（默认）

## 这条工作流是什么

用户已有素材（粘贴文本 / 文件 / 链接 / 口述转写），把它加工成小红书笔记。

## 分几步

1. 取材与理解
2. 澄清与定语气
3. 创作简报（📍停下等你确认）
4. 成稿与自检
5. 终稿交付（📍停下等你确认）
6. 发布（可选）

## 每步做什么

### 1. 取材与理解

- 读取输入：粘贴文本直接读；本地文件读文件；URL 用 webfetch（需要复杂操作时委托 browser-agent）
- 提炼：主题 / 目标读者 / 可用素材 / 信息缺口
- 用一句话向用户复述理解（"我看完了，这是关于 XX 的内容"）

### 2. 澄清与定语气

- 一次最多问 2 个问题（读者、目的、语气、是否需要调研补料）
- 每个问题给推荐答案，允许用户回"都行"
- 语气按 `references/tone-guide.md` 判断，并说明理由

### 3. 创作简报（📍）

按 `templates/deliverable.md` 的简报部分输出：角度 / 读者 / 语气（含判断理由）/ 结构（分几段、每段写什么）/ 素材来源 / 预计字数。

→ **停下等确认**。用户确认前不动笔。

### 4. 成稿与自检

产出：标题候选 3-5 个（≤20 字）/ 封面文案 + 配图建议 / 长文正文 / 描述（约 100 字）/ 标签。

按 `references/xhs-spec.md` 自检：事实引用、合规红线、字数、无 markdown 符号、引号统一、「收藏/评论/分发/转化」引流话术齐全。

### 5. 终稿交付（📍）

输出终稿全文（按 `templates/deliverable.md` 格式）。

→ **停下等确认**。用户说"定稿"后走发布。

### 6. 发布（可选）

见 `workflows/publish.md`。

## 哪几步停下来等你

- 📍 **简报确认**：角度与结构 OK 才写正文
- 📍 **终稿确认**：全文 OK 才发布
