# 小红书规范（实战沉淀）

## 一、长文 / 图文模式（最重要）

- 图文长文发布时，平台会把文章转成图片
- **正文里的 markdown 不会渲染**：`**加粗**` 会原样显示星号 → 禁止使用
- 结构改用：空行分段、序号（①② / 1️⃣）、emoji 小标题、`·` 列表
- 引号统一「」，不要混用英文引号
- 数字与英文两侧留空格更易读
- 正文长度上限约 1000 字（含标点与 emoji），超出需精简

## 二、标题

- **≤20 字**（含 emoji、英文按字符计；平台硬限制）
- 活动类：按活动要求包含指定元素（如 howto），并带规定话题
- 推荐结构：痛点 / 结果 + 方法（例："howto让AI记住你的规矩"）

## 三、描述（标题下方正文区）

- 出现在标题下方，**必须精简**（约 100 字内）；太长会劝退
- 承担引流动作，四类齐全：
  1. 收藏：「先收藏 ⭐」
  2. 评论：「你被 XX 气到过吗？评论区聊聊 👇」
  3. 分发：「转给还在 XX 的同事」
  4. 转化：「回复「关键词」领详细版」
- 结尾固定：话题标签（2-4 个）+ @（活动要求的官方号）

## 四、引流与限流

- 评论区外链易被限流 → 用"回复关键词领取 / 私发"替代裸链
- 不写"加微信""私域""二维码"等敏感词
- 活动双话题必须带全（如 `#我这行的AI路` + `#HOWTO`）

## 五、合规红线

- 极限词：最、第一、100% 等（广告法）
- 医疗 / 金融 / 教育的功效承诺
- 编造数据与引用；转载未授权内容
- 他人隐私信息（姓名、工号、客户名等）需脱敏

## 六、发布备注（交付物必含）

- 话题标签清单
- @ 清单（活动官方号、账号）
- 配图建议：封面 + 内页 3-5 张（文件夹实拍 / 流程截图 / 对话截图 / 总结图）
- 评论区置顶文案建议
