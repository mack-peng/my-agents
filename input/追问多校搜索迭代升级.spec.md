# 追问多校搜索迭代升级 Spec

## Problem

| # | 问题 | 影响面 |
|---|------|--------|
| 1 | `追问→生成搜索词` 将多校+人口特征词拼接成单一搜索词（例：`四川大学 宿舍 女生 山东大学 宿舍 女生 中国海洋大学 宿舍 女生`），知识库返回空 | 所有含 ≥2 所学校或性别词的追问 0 命中 |
| 2 | `追问智能回复` 在 context 为空时凭空编造学校宿舍、校园环境等具体数据（复现 case：编造了川大江安校区 3 室 1 厅、北航沙河校区独立卫浴等虚假信息） | 用户获得完全虚构信息，信任崩塌 |
| 3 | 知识库按单一学校+维度索引，不支持跨校混合查询，但当前 prompt 未拆分 | 多校查询命中率 0% |

### Part 1 — 追问→生成搜索词 prompt 改造

节点 ID: `1747600000001`

| # | Requirement | Mockup & Description |
|---|-------------|---------------------|
| 1 | 改为结构化两行输出 | system prompt 替换为：<br/>`学校:{空格分隔}`<br/>`维度:{空格分隔}`<br/><br/>示例输入：「这些学校哪个更适合女生读？宿舍条件怎么样？」<br/>示例输出：<br/>`学校:四川大学 山东大学 中国海洋大学`<br/>`维度:宿舍 校园环境`<br/><br/>学校名从对话历史 memory 中提取（window=10），维度从用户当前问题+历史中提取 |
| 2 | 维度映射表内嵌到 prompt | `宿舍/寝室 → 宿舍`<br/>`食堂/吃饭 → 食堂`<br/>`适合女生/适合男生 → 校园环境 安全`<br/>`社团活动 → 社团`<br/>`实验室/科研 → 实验室`<br/>`录取分/分数线 → 录取分数`<br/>`就业/工作 → 就业前景`<br/><br/>禁止输出「女生」「男生」「适合」等非索引词 |
| 3 | 多校提取策略 | 从对话历史 memory 中识别所有已讨论的学校名，不限于当前消息 |
