# Join Us 页面产品优化 Spec

## Problem

加入我们页面是公司的核心人才/合伙人招募入口，承接两个产品线——**小橙有门**（AI 便民小程序）和**小橙富能农业**（季节性农产品全托管电商平台）——的团队建设需求。当前页面存在以下问题：

| # | 问题 | 影响面 |
|---|------|--------|
| 1 | 无申请表单 | 用户需主动发邮件/打电话，心理门槛高，转化流失 |
| 2 | CTA 跳转腾讯文档 | 关键信息外跳到第三方，用户跳出后不回来 |
| 3 | 缺少合伙模式完整说明 | 收益分成、时间投入、风险等核心问题仅一句话带过 |
| 4 | 无信任信号 | 没有现有团队规模、已服务数据、合伙人故事或证言 |
| 5 | 无 FAQ | 潜在合伙人的顾虑无人解答，信息不透明 |
| 6 | 无提交后预期 | 用户联系后不知道接下来会发生什么 |
| 7 | 角色列表与实际不符（小橙富能农业） | 列了前后端开发，但平台已建成，实际需要的是市场/运营/UI/客服 |
| 8 | 价值主张不具体（小橙富能农业） | 没有讲清楚"全托管电商平台"是什么、和农户怎么合作、盈利模式 |

**影响面**：合伙人招募转化率低，项目缺人影响产品迭代速度。

## Related Spec

无（独立产品优化，无上下游依赖 Spec）

## Solution

### Part 1 — 小橙有门板块

| # | Requirement | Mockup & Description |
|---|-------------|---------------------|
| 1 | **招募角色** | 保留现有 6 类角色：产品 / 前端（React/微信小程序）/ 后端（Java）/ 测试 / UI / 推广 |
| 2 | **CTA 组合** | **主要按钮**：「立即申请」→ 滚动至底部统一表单<br/>**次要按钮**：「查看项目章程」→ 外链腾讯文档，新标签页打开 |
| 3 | **合作流程可视化** | 新增合作流程步骤条：<br/>Step 1 — **了解**：阅读项目章程，认可章程的价值观<br/>Step 2 — **沟通**：与项目组成员对话沟通，进一步了解项目细节<br/>Step 3 — **签约**：项目组同意后，拉入工作微信群，介绍相关信息，写入章程<br/>Step 4 — **分成**：按实际情况参与项目角色，获取任务积分，每月例会计算分成 |
| 4 | **合伙人证言** | 新增真实合伙人证言区块，增强信任信号：<br/>- 刘先生（产品）："在这里做产品不需要写复杂的 PRD，大家讨论清楚就直接开干了。每周看看积分表就知道自己的贡献被看见了，比在大厂写周报实在。"<br/>- 罗先生（测试）："平时下班没事干，在这里帮项目跑跑测试、提提 bug，一个周期下来积分不少。关键是退出后积分还在，这个模式让我很放心。"<br/>- 张小姐（UI）："一开始担心远程协作沟通成本高，实际发现大家都很高效。设计稿提上去，反馈很快，改完就上线，很有成就感。" |
| 5 | **专属 FAQ** | 新增 FAQ 折叠区：<br/>- 没有技术背景可以加入吗？ → 可以。我们有 Dify 编排以及小红书运营等相关工作，不需要懂技术<br/>- 收益具体怎么分配？什么时候能拿到？ → 参与项目后按积分表记录贡献。每个项目周期完成后结算积分，每月第一例会根据收入与积分表中的比例进行分成 |

### Part 2 — 小橙富能农业板块

| # | Requirement | Mockup & Description |
|---|-------------|---------------------|
| 1 | **板块定位与价值主张** | 副标题改为：**季节性农产品全托管电商服务平台 — 合伙人招募**。新增四要素价值卡片：<br/>- **我们做什么**：为零技术能力的农户搭建直达消费者的线上销售通道，农户只管种和发，我们全包技术和运营<br/>- **为什么有机会**：大量农户依赖中间商收购和朋友圈卖货，自建电商门槛高、成本高。一套平台可服务 N 个农户<br/>- **怎么赚钱**：两种模式：A 类 200 元/月技术服务费；B 类加价 5%-10% 佣金销售。不碰货、无库存、轻资产<br/>- **目前进展**：小程序已上线，累计用户 203 人，完成 4 笔订单。项目章程与 SOP 已建立，正在跑通 MVP |
| 2 | **招募角色** | 替换为 4 类实际需要的角色：<br/>- **市场推广经理**：农户招募与签约、商品信息收集、商家维护（沟通谈判、本地市场熟悉）<br/>- **UI / 视觉设计**：商品主图、详情页、宣传素材、DM 单设计（PS/Figma、电商页面审美）<br/>- **客服与运营**：用户接待、售后处理、订单履约跟进（服务意识、微信沟通）<br/>- **运营推广**：小红书图文/视频、公众号、视频号、广告投放（小红书运营、文案、视频剪辑） |
| 3 | **合作模式说明** | 新增合作模式 FAQ 区块：<br/>- **需要全职吗？** → 不用，团队成员都有本职工作，根据下周时间决定是否参与本轮飞轮<br/>- **没有技术背景可以吗？** → 可以，市场推广、客服、运营、设计都不需要编程<br/>- **收益怎么分配？** → 每产品按月核算利润 → 20% 归项目（再投资/应急），80% 团队分 → 运营部 10% / 财务部 10% / 市场推广部 80%（含市场经理 60%、UI 20%、客服 20%）<br/>- **退出后收益还在吗？** → 退出后仍在股东群，积分不消失，继续参与后续分成<br/>- **远程还是坐班？** → 全程远程协作，不限定城市 |
| 4 | **CTA 组合** | **主要按钮**：「立即申请」→ 滚动至底部统一表单<br/>**次要按钮**：「查看项目章程」→ [https://docs.qq.com/doc/DZU9OQ0dNdFV0dUFz](https://docs.qq.com/doc/DZU9OQ0dNdFV0dUFz)（新标签页） |
| 5 | **合作流程可视化** | 新增合作流程步骤条：<br/>Step 1 — **了解**：阅读项目章程，认可项目价值观和分配模式<br/>Step 2 — **沟通**：与现有团队成员沟通，了解项目进展和日常节奏<br/>Step 3 — **签约**：项目组同意后，拉入工作群，介绍相关流程，写入章程<br/>Step 4 — **分成**：按角色参与任务，获取积分，每月例会按比例分成 |
| 6 | **合伙人证言** | 新增真实合伙人证言区块：<br/>- 邱小姐（UI / 视觉设计）："每季农户的产品都不一样，设计主图和详情页就像在开盲盒，很有意思。看到自己做的页面帮农户卖出货，比做大厂需求稿有成就感多了。"<br/>- 胡小姐（财务）："账目公开透明，每一笔收入和支出大家都能看到。月初算分成的时候，看着积分表对应到实际收入，大家都很有干劲。"<br/>- 张先生（市场推广）："一开始跑去村里找农户聊，他们听说不要钱就能上网卖，都不太信。做成第一个案例后，现在有农户主动来问了。" |
| 7 | **专属 FAQ** | 新增 FAQ 折叠区：<br/>- 没有技术背景可以加入吗？ → 可以，市场推广、客服、运营、设计都不需要编程<br/>- 收益具体怎么分配？ → 每产品按月核算利润 → 20% 项目基金，80% 团队分配 → 运营部 10% / 财务部 10% / 市场推广部 80%（市场经理 60%、UI 20%、客服 20%）<br/>- 前期有什么进展？ → 小程序已上线，累计用户 203 人，完成 4 笔订单。项目章程、SOP、任务清单均已建立 |

### Part 3 — 共享部分

| # | Requirement | Mockup & Description |
|---|-------------|---------------------|
| 1 | **跨项目合伙模式说明区** | 在两个项目 section 之后、表单之前，增加独立区块：<br/>- **核心差异**：非雇佣关系，无固定工时约束；贡献决定收益（多劳多得）；退出后历史贡献保留，继续享受收益分成<br/>- **适合谁**：想用业余/碎片时间参与创业的技术人、运营/市场人员、UI/UX 设计师；认可"付出有回报"理念的实干者<br/>- **不适合谁**：只接受固定月薪、无法承诺基本投入时间、不认可贡献制分配原则 |
| 2 | **统一申请表单** | 页面底部统一"立即申请"表单。<br/>**入口位置**：页面底部（两个项目 section 之后），统一的"立即申请"按钮<br/>**表单字段**：<br/>  - 姓名（必填）<br/>  - 联系方式（手机 / 微信，必填）<br/>  - 意向项目（单选：小橙有门 / 小橙富能农业 / 不限）<br/>  - 意向角色（下拉单选，根据意向项目动态切换选项）<br/>    - 小橙有门：产品 / 前端 / 后端 / 测试 / UI / 推广<br/>    - 小橙富能农业：市场推广经理 / UI 视觉设计 / 客服与运营 / 运营推广<br/>  - 个人简介/经历（textarea，选填，不超过 500 字）<br/>**提交后行为**：弹窗"感谢提交，我们将在 3 天内联系你" + Chatwoot 自动欢迎消息<br/>**后台通知**：提交后通过 webhook 通知企业微信群 |
| 3 | **通用 FAQ** | 跨项目 FAQ 折叠区：<br/>- 需要全职投入吗？每周大概多少时间？ → 不用全职投入。团队成员都有本职工作，根据自己下一周有多少时间决定是否参与本轮项目飞轮<br/>- 退出后真的还能有收益吗？ → 退出后仍在股东群中。积分不会消失，你的积分依然参与后续分成<br/>- 远程还是坐班？在哪个城市？ → 全程远程协作，不限定城市<br/>- 合伙人之间有纠纷怎么处理？ → 目前团队无纠纷。如有纠纷可找公司调解，团队成员都比较讲理 |
| 4 | **申请提交后的跟进机制** | - 前端：弹窗"感谢提交，我们将在 3 天内联系你"<br/>- 即时通讯：触发 Chatwoot 自动欢迎消息<br/>- 后台通知：表单提交后通过 webhook 通知企业微信群，项目组及时知晓新申请 |
