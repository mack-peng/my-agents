# 封面与发布物料（小红书默认）

适用：影片交付需要配套封面 / 标题 / 正文。默认平台小红书；其他平台按用户说明调整尺寸与文案。

## 尺寸与平台

- **默认小红书竖版封面 3:4：1080×1440**（`cover-3x4.html` → `cover-3x4.png`）
- 4:3（1440×1080）**仅在用户明确要求时生成**，不默认双份
- 封面是**独立 HTML 截图**，不是影片时间线里的 clip；放影片工程根目录（与 `film.html` 同级），不放 `assets/`

## 封面制作

1. **复用影片设计语言**：`<link rel="stylesheet" href="styles.css">` 共用颜色/字体变量；封面自己的布局写在页内 `<style>`，不污染影片页面
2. **尺寸精确**：`html, body` 与 `.cover` 都设为 1080×1440（或 1440×1080），`<meta name="viewport">` 同步
3. **光学居中（重要）**：主内容块用 `display:flex; flex-direction:column; justify-content:center` 垂直居中，顶部品牌/期号、底部日期用绝对定位；因顶部/底部 chrome 会拉低视觉重心，主内容与数据卡整体加 `translateY(30–50px)` 下移校准——**不能只靠 flex-start**（已实测教训：纯 flex-start 显得内容偏上）
4. **文案来自已确认内容**：标题从分镜/正文提炼（≤15 字为佳），数据卡数字必须来自闸门确认过的选取表，不编新数字
5. **背景**：复用影片背景图（`assets/img/`），加深色遮罩保证文字对比度；`filter: brightness(<0.4)` + 渐变遮罩

## 截图与验收

- 用 Playwright（本机已装 `playwright-core` + chromium-headless-shell）打开 HTML 截全页 PNG，视口与封面尺寸一致
- 验收（全尺寸看图）：
  - 内容是否光学居中（不偏上/不偏下）
  - 文字对比度足够（暗遮罩上浅色字）
  - 数字与影片/选取表一致
  - 边缘无裁切、无溢出
- 输出到影片工程根目录；**禁止写 Desktop / Downloads**

## 发布文案

- **标题**：一句话钩子，与封面主标题一致或呼应（小红书 ≤20 字）
- **正文**：5 个要点 bullet（每个 = 模型/事件 + 一个关键数字）+ 主线总结 + 互动问句
- **标签**：按内容调整，5–6 个（如 `#AI调研 #大模型 #DeepSeek #Gemini #开源模型`）
- 数字/事实**必须**与影片和源文档一致——发布文案也是对外内容，红线同 `from-doc.md`（不改数字/引用/结论）

## 交付清单

- 封面 PNG 路径（如 `cover-3x4.png`）
- 标题 / 正文 / 标签（直接可复制）
- 若影片本身需要片头封面帧，另按分镜表执行，不与发布封面混用
