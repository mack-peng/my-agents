# 封面与发布物料（小红书默认）

适用：影片交付需要配套封面 / 标题 / 正文。默认平台小红书；其他平台按用户说明调整尺寸与文案。

## 尺寸与平台

- **默认小红书竖版封面 3:4：1440×1920**（与 image-agent `platform-specs.md` 统一；`cover-3x4.html` → `cover-3x4.png`）
- 4:3（1440×1080）**仅在用户明确要求时生成**，不默认双份
- 封面是**独立 HTML 截图**，不是影片时间线里的 clip；放影片工程根目录（与 `film.html` 同级），不放 `assets/`
- **封面 3:4 与视频 9:16 各自独立、互不通用**（2026-10 复盘确认）：封面按信息流卡片比例 3:4 设计；视频按全屏 9:16 制作与导出。Studio 导出预设里的「小红书」原本是 feed 3:4——**本 fork 已改为 vertical 9:16**（`export-spec.ts`，commit d033389 @ feat/bailian-provider）；同步上游时留意此处分歧。9:16 片子若用 3:4 预设导出：contain 加黑边 / cover 裁上下——都不接受

## 封面内容原则（2026-11 调研 · 本 agent 独立维护）

- **写结果，不写分类**：主标题用「读者能得到什么 / 会想追问什么」，不用「上线了 / 上新 / 正式发布」这类分类 + 广告腔（实测好例：`你是什么体质？`；坏例：`体质测评上线了`）
- **字数**：主标题 3–15 字，封面文案 10 字上下；放不下先改文案，不缩字号硬塞
- **封面与发布标题分工**：封面给结果/冲突/画面感，标题给人群/条件/数字；两句连起来读不像同一句话说两遍
- **每个字正文能兑现**：社区公约反夸张/猎奇/标题党；封面承诺正文兑现不了 = 完读与分发双输
- **一个视觉中心**：主体 ≤3、文字不压主体/脸、对比够（描边或压暗底）；主色 ≤3、字体 ≤2
- **缩略图自检**：缩到 320px 宽，1 秒能说出「这张在承诺什么」；发布端可传 4 张封面 PK，10 小时后按真实点击率择优
- **别用视频抽帧当封面**：封面单独做图，缩略图里才是完整设计
- 数据卡数字仍以「文案来自已确认内容」为准（见下）

## 封面 feed-first（2026-11 实测入档）

- **信息流里封面被缩到 ~300px 宽**：原图 1440 宽下，文字 < 90px 在 feed 里 ≈ <19px，等于不可读。**封面只放大字，删光小字**（日期/期号/来源/模型名行 → 下沉正文）
- **刊名（身份）≥ 120px**：系列封面必须让用户一眼知道"这是什么栏目"，20px 灰色 mono 行在 feed 里等于不存在
- **关键信息压进 feed 1:1 可见区**：3:4 封面在 feed 被顶部锚定裁切为 ~1:1；1440×1920 封面的关键信息必须在 y0–1440 内
- **封面实拍 + 大字**：Unsplash / AI 出图做满幅背景 + 左侧纸白渐变 scrim 压大字（文字全部 HTML，图只做视觉）；实拍署名写正文末尾，不占封面小字
- **feed 1:1 预览必做**：`node image-agent/scripts/feed-preview.mjs <cover.png>` → `feed-1x1.png` + `feed-1x1-320.png`，看 feed 里实际显示效果
- **封面双落点**：工程（HTML / assets / recipe.md）留在 image-agent 侧 `output/<slug>/`；成品 PNG 拷贝到**影片工程根** `cover-3x4.png`；验收读 `cover-qa.json`（`shoot --cover-qa` 产出），缺文件按未交付处理

## 封面制作

- **主题优先（Nº06 教训）**：周刊/系列封面的大标题写**内容主题本身**（如「11 月第一周 / AI 动态」），观点式标题（"开源追近，闭源买不到"）降级为副题或一句概括；主标题 ≤15 字最佳
- 中文大标题与数字之间不空格（「11月第一周」紧凑；小字号正文保留空格）；数据卡的数字仍全部取自已确认选取表
- **尺寸要真改不要缩放**：同一封面设计改 1080×1440 时，`--w/--h` 变量与 `<meta name="viewport">` 必须同步改（只截小图会得到 1440×1920 的缩略图）
- **外包 image-agent（用户点名"use image-agent"做封面时）**：读其 `AGENTS.md` + `workflows/make-cover.md`，设计/渲染/自动 QA 走它的流程，付费 AI 生图先经用户确认。产物**双落点**：工程（HTML / assets / `recipe.md`）留在 image-agent 侧 `output/<slug>/`；成品 PNG 拷贝到**影片工程根** `cover-3x4.png`（Studio 交付清单引用它）。封面内容口径仍受本仓库闸门约束——数字/标题来自已确认的选取表，不改事实

1. **复用影片设计语言**：`<link rel="stylesheet" href="styles.css">` 共用颜色/字体变量；封面自己的布局写在页内 `<style>`，不污染影片页面
2. **尺寸精确**：`html, body` 与 `.cover` 都设为 1080×1440（或 1440×1080），`<meta name="viewport">` 同步
3. **光学居中（重要）**：主内容块用 `display:flex; flex-direction:column; justify-content:center` 垂直居中，顶部品牌/期号、底部日期用绝对定位；因顶部/底部 chrome 会拉低视觉重心，主内容与数据卡整体加 `translateY(30–50px)` 下移校准——**不能只靠 flex-start**（已实测教训：纯 flex-start 显得内容偏上）
4. **文案来自已确认内容**：标题从分镜/正文提炼（≤15 字为佳），数据卡数字必须来自闸门确认过的选取表，不编新数字
5. **背景**：复用影片背景图（`assets/img/`），加深色遮罩保证文字对比度；`filter: brightness(<0.4)` + 渐变遮罩

## 截图与验收

- 用 Playwright（本机已装 `playwright-core` + chromium-headless-shell）打开 HTML 截全页 PNG，视口与封面尺寸一致
- 验收（全尺寸看图）：
  - 内容是否光学居中（不偏上/不偏下）
  - 文字对比度足够（暗遮罩上浅色字）
  - 数字与影片/选取表一致
  - 边缘无裁切、无溢出
- 输出到影片工程根目录；**禁止写 Desktop / Downloads**

## 发布文案

- **标题**：一句话钩子，与封面主标题一致或呼应（小红书 ≤20 字）
- **正文**：5 个要点 bullet（每个 = 模型/事件 + 一个关键数字）+ 主线总结 + 互动问句
- **标签**：按内容调整，5–6 个（如 `#AI调研 #大模型 #DeepSeek #Gemini #开源模型`）
- 数字/事实**必须**与影片和源文档一致——发布文案也是对外内容，红线同 `from-doc.md`（不改数字/引用/结论）
- 标题与封面主题呼应（主题式封面 → 标题用"11 月第一周 AI 动态盘点"；观点式封面 → 标题呼应观点）

## 交付清单

- 封面 PNG 路径（如 `cover-3x4.png`）
- 标题 / 正文 / 标签（直接可复制）
- 若影片本身需要片头封面帧，另按分镜表执行，不与发布封面混用
