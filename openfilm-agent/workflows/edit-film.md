# 改片（定向修改已有影片）

适用：用户对已有影片做定向修改（使用入口菜单 3）。红线同 AGENTS.md「人机协作规则」。

## 流程

1. **打开在场**：`npx -y openfilm@latest open output/<film-name>` — 让用户在 Studio 里实时看到修改过程
2. **先读后改**：读 `film.html` + 涉及页面。人在 Studio 可能已经改过——`overrides` 与 `locked` 轨道是人的修改，**原样保留**
3. **只改意图内**：不顺手重构、不动无关镜头
4. **`look` 复验**：影片目录内跑，确定性 + 报错干净才算完
5. 用户要文件才 `render`；否则 Studio 里看效果

## 常见改片任务 → 做法

- **文案 / 数字**：改页面里对应 DOM 元素（Studio 改元素不是像素——保持元素可编辑）；改完同步检查排版是否仍成立
- **配色 / 字体**：改页面 `<style>` 里的颜色变量；品牌色集中在公共处，方便统一换
- **节奏**：改页面动效的时间参数（`frame(t)` 里的起点/时长/缓动），或 film.html 的 `at` / `#t=` / `speed`
- **换素材**：新文件拷贝进 `assets/`，改 `src` 引用（保持 `#t=` 语义不变则时机不乱）；旧素材确认无人用再删
- **加 / 删镜头**：一镜一页——新增页面 + film.html 加 clip；删除则移除 clip 与页面文件，并检查前后 `at` 衔接
- **横竖互转**：新建竖/横工程，页面**版面重排**（字号、留白、构图按新版面重新设计），不是整体缩放

## 结构性改动（先方案后动手）

以下属于重建级，不能"顺手改"：**横竖互转、加/删 ≥2 镜、换片型风格、重排叙事顺序**——先给轻量方案（要点 + 新分镜表）并等用户确认，再按 `workflows/build-film.md` 的闸门执行（对齐 AGENTS.md「编排纪律」）。

## 红线

- ❌ 不重编码媒体（裁只改 `#t=`、快慢只改 `speed`）
- ❌ 不碰 `locked` 轨道；不清 `overrides`
- ❌ 不跳过 `look`；用户没要文件不 `render`
- ❌ 改完不做交付说明（改了什么、哪里可再改）
