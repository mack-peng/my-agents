# 改片（定向修改已有影片）

适用：用户对已有影片做定向修改（使用入口菜单 3）。红线同 AGENTS.md「人机协作规则」。

## 流程

1. **打开在场**：`openfilm open output/<film-name>` — 让用户在 Studio 里实时看到修改过程
2. **先读后改**：读 `film.html` + 涉及页面 + 相关 VTT。人在 Studio 可能已经改过——`overrides` 与 `locked` 轨道是人的修改，**原样保留**
3. **只改意图内**：不顺手重构、不动无关镜头
4. **`look` 复验**：影片目录内跑，确定性 + 报错干净才算完（**不校验字幕**，字幕另抽帧）
5. **默认不导出**：交付 = Studio 预览 + 改动说明；仅用户当次明确要求时 agent 执行（无字幕 `openfilm render`，带字幕 Studio 烧录）

## 常见改片任务 → 做法

- **文案 / 数字**：改页面里对应 DOM 元素（Studio 改元素不是像素——保持元素可编辑）；改完同步检查排版是否仍成立
- **配色 / 字体**：改页面 `<style>` 里的颜色变量；品牌色集中在公共处，方便统一换
- **节奏**：改页面动效的时间参数（`frame(t)` 里的起点/时长/缓动），或 film.html 的 `at` / `#t=` / `speed`
- **换素材**：新文件拷贝进 `assets/`，改 `src` 引用（保持 `#t=` 语义不变则时机不乱）；旧素材确认无人用再删
- **换音色 / 重生成配音**：重生成全部 TTS clip（同名覆盖旧 take，旧转写/字幕失效）→ 量新时长 → 回填各镜 `at`/`duration`（VO 时长变了总时长就变，不硬凑旧时长）→ 调 `speed` 防重叠 → 校正 VTT → `look` → 字幕抽 4 帧 + 混音对基线验收（见 `references/audio-subtitles.md`）
- **加 / 改字幕**：每条配音旁放同名 `.vtt`；ASR 只取时间，文字按口播稿校正；改 `speed` 字幕后随，换音频/音色要重做 VTT；竖屏基线 `y≈0.786`（见 `references/audio-subtitles.md`），压住正文/下一章/结尾大字时经 **Studio UI/API** 调位置（禁止文本编辑器改 `.film/subtitles.json`）；交付走 Studio 烧录，默认不由 agent `render`
- **加 / 删镜头**：一镜一页——新增页面 + film.html 加 clip；删除则移除 clip 与页面文件，并检查前后 `at` 衔接
- **横竖互转**：新建竖/横工程，页面**版面重排**（字号、留白、构图按新版面重新设计），不是整体缩放

## 结构性改动（先方案后动手）

以下属于重建级，不能"顺手改"：**横竖互转、加/删 ≥2 镜、换片型风格、重排叙事顺序**——先给轻量方案（要点 + 新分镜表）并等用户确认，再按 `workflows/build-film.md` 的闸门执行（对齐 AGENTS.md「编排纪律」）。

## 红线

- ❌ 不重编码媒体（裁只改 `#t=`、快慢只改 `speed`）
- ❌ 不碰 `locked` 轨道；不清 `overrides`
- ❌ 不跳过 `look`；默认不导出（仅用户当次明确要求时执行），不自动烧录导出
- ❌ 改完不做交付说明（改了什么、哪里可再改）
