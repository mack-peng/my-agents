# 引导建片（新建影片完整流程）

适用：用户要新建影片（使用入口菜单 1），或描述了内容与目标但没有现成片子。
原则：**一次采集齐 → 选片型 → 分镜 sign-off 后才动手 → 制作 → 交付说明**。

## Step 1 采集需求（一次问齐，不挤牙膏）

- **内容与目标**：主题一句话 + 3–5 个要点（要展示什么）；想让人看完记住什么
- **受众与平台**：给谁看、发哪里（小红书 / 官网 / 内嵌 / 群发）
- **形态**：时长（默认 8s）；横版 1920×1080 / 竖版 1080×1920 / 双版；要不要声音（配音/音乐/音效需要用户在 Studio → Settings → Providers 配服务商自己的 key，见 AGENTS.md「入口与命令 · get」）
- **素材**：放仓库根 `input/`（图片 / logo / 视频 / 音频 / 文案定稿 / 真实数字 / 字体），并说明哪些必须用；没有素材也行——图形与版面全部代码生成
- **硬约束**：必须出现的字（品牌名、免责声明等）、禁用元素、截止时间

用户未提供的项用默认值继续（不阻塞），并在方案里标明默认假设。

## Step 2 选片型

先跑 `npx -y openfilm@latest skills` 拿最新清单，常用映射：

| 主题 | 推荐 skill |
|---|---|
| 产品发布 / 官网片头 / 高级感宣传 | `motion-graphics`（首选）、`keynote` |
| 教学讲解 / 微课 / 概念解释 | `whiteboard` |
| 录屏演示 / 功能教程 | `screen-demo` |
| 长视频切片（抖音 / Reels / Shorts） | `long-to-short` |
| 歌曲 / 歌词 MV | `lyric-video` |
| 照片回忆 / 年度回顾 | `vintage-film` |
| 复刻参考视频 | `replicate` |
| 口播小窗 / 讲解主持 | `presenter-pip` |
| 拼贴 / 手账 / 杂志风 | `collage` |

- 推荐 1–2 个并给一句理由；用户点名片型则直接 `npx -y openfilm@latest skill <name>`，**整篇读完照做**（技能文件夹只读，用到的文件复制进影片工程）
- skill 是方法与质量红线（属于这个主题、用真实数字与品牌、保持可编辑），**不是现成模板**——设计仍要为这个主题现做

## Step 3 方案 sign-off（未确认不动手）

产出并等用户确认：

1. 一句话**概念**（这支片子的 idea，为什么贴主题）
2. **分镜表**：镜号 ｜ 时长 ｜ 画面内容 ｜ 动效意图 ｜ 文案（精确到字）
3. 素材清单：用 `input/` 里哪些文件（列文件名）
4. 假设与默认值（用户没明说的项）

确认后：分镜表**转为 TODO 清单**（每镜一项），制作中按 AGENTS.md「编排纪律」逐镜跟踪，交付前清零。

## Step 4 制作（确认后）

按 AGENTS.md「标准工作流 · 做片」执行：

1. `npx -y openfilm@latest open output/<film-name>` 建片（Studio 先在场）
2. 写页面 + 编排 film.html（`frame(t)` 铁律；一镜一页）
3. 影片目录内 `look` 循环校验，修到干净（同步勾 TODO）
4. **第一版完成 → 展示接触表并等用户反馈**（"第一版完成，请确认（OK 继续 / 指出要改的）"），按反馈迭代，不自认为完成
5. Studio 人机共编（保留 `overrides` 与 `locked` 轨道）
6. 用户要文件才 `render`；否则 Studio 里预览/导出

双版（横 + 竖）就建两个工程（如 `xxx` 与 `xxx-vertical`），页面同源改造、版面重排而非缩放。

## Step 5 交付说明

- 构思与贴题理由（一两句）
- 每个数字 / 事实的来源
- 用户下一步能提供什么让片子更好（logo、真实截图、定稿文案）
- 可改点：哪些文字 / 数字在页面里可直接改

## 反模式

- ❌ 用可套任何公司的泛化动画（skill 红线：必须属于这个主题）
- ❌ 编数字 / 编引用；用 logo 时重画而不是原样使用
- ❌ 未 sign-off 就动手；跳过 `look` 直接交付
- ❌ 动 `locked` 轨道 / `overrides`；重编码媒体文件
- ❌ 擅自下载大文件；声音服务未配 key 就假装能用
