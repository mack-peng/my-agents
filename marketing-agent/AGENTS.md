## 一、市场营销专业基础知识

### 1.1 什么是市场营销

市场营销是以满足客户需求、实现企业利润为目标的综合性学科，贯穿于企业经营活动的全过程。核心是**为顾客创造价值**。

### 1.2 市场营销决策链条

**SWOT → STP → 4P**

| 阶段 | 说明 |
|------|------|
| **SWOT** | 分析优势(S)、劣势(W)、机会(O)、威胁(T) |
| **STP** | 市场细分(Segment) → 目标(Target) → 定位(Position) |
| **4P** | 产品(Product)、价格(Price)、渠道(Place)、促销(Promotion) |

### 1.3 课程知识体系

| 模块 | 内容 |
|------|------|
| **商业知识** | 宏微观经济学、财务管理、人力资源管理、运营管理 |
| **市场基础** | 营销学基础、定价管理、渠道管理、整合营销、品牌学 |
| **市场战略** | STP、RBV 等战略理论模型 |
| **消费者行为** | 数据分析、消费者心理学、市场调研 |
| **数字营销** | 电子商务、数字营销、智能媒体经营、大数据分析 |

## 二、市场营销核心理论

| 理论 | 说明 |
|------|------|
| SWOT 分析法 | 分析企业优势、劣势、机会和威胁，制定对策 |
| 产品生命周期理论 | 起步→成长→成熟→衰退，各阶段不同策略 |
| 马斯洛需求层次理论 | 生理→安全→社交→尊重→自我实现 |
| 市场细分理论 | 将市场分割成若干细分市场，更好定位目标消费者 |
| 竞争策略理论 | 低成本策略、差异化策略、集中化策略 |
| 购买决策过程模型 | 问题认知→信息搜集→评估分析→购买决定→购后评价 |
| AIDA 模型 | 注意→兴趣→欲望→行动 |

## 三、就业方向与职业发展

### 3.1 常见就业领域

| 领域 | 说明 | 代表企业 |
|------|------|---------|
| **广告公司** | 广告策划、品牌传播 | 4A 公司、叶茂中 |
| **营销公司** | 销售和渠道管理 | 胜初、房地产代理 |
| **营销咨询公司** | 品牌战略咨询 | 科特勒、特劳特中国、里斯中国 |
| **企业市场部** | 市场专员→品牌经理→渠道经理 | 各行业头部企业 |
| **公关公司** | 全案公关、活动执行 | 蓝色光标、万博宣伟 |
| **市场研究机构** | 市场分析和研究 | 新生代、零点、CTR |

### 3.2 核心岗位

| 岗位 | 职责 |
|------|------|
| 品牌经理 | 制定品牌定位策略，管理品牌形象 |
| 产品经理 | 研究市场需求，设计推出符合趋势的产品 |
| 市场调研分析师 | 定量定性调研，分析市场趋势 |
| 市场营销经理 | 项目策划、组织协调、计划制定、预算制定 |
| 数字营销专员 | 开发数字化营销渠道 |
| 客户关系管理师 | 管理客户关系，提高客户忠诚度 |
| 市场推广专员 | 制定推广方案，组织执行营销计划 |

### 3.3 职业发展路径

入门 researcher → Senior researcher → Manager → Senior Manager → Associate Director → Director

### 3.4 核心能力要求

1. **对人性的洞察能力** — 营销的核心是人
2. **理性思考、感性表达** — 熟练使用 SWOT/PEST/Five Forces 等分析框架
3. **不断学习的能力** — 广泛涉猎营销理论、实践案例和人文社科
4. **数据分析和判断能力** — 掌握 Excel、SPSS、Python 等工具
5. **沟通与团队合作的能力** — 对不同对象采取不同沟通方式

## 四、2025 营销行业七大趋势

**来源：** Illuminera 意略明 · 周波（Paul Zhou）

### 趋势 01：营销自动化初具规模

算法驱动的自动化浪潮将席卷营销行业。目前最大障碍是二方大数据平台 API 接口未标准化开放。未来数年将有实质性突破。

### 趋势 02：新一代大数据油田应运而生

消费者数据隐私保护将参照"欧盟路径"。现有平台间大数据打通难度加大，合法合规的新一代大数据平台将填补空白。

### 趋势 03："整合 ROI"成为金标准

"品"与"效"的对立是行业最大伪命题。拥抱 cROI（Consolidated ROI）的品牌，决策更具透明度，营销效率更高。

### 趋势 04：营销全链路整合蔚然成风

大数据时代，一切营销动作可在真实环境下测试并直接联系 cROI。统一语言体系使全链路整合势在必行。

### 趋势 05：品牌私域商业模式不可或缺

公域流量价格高回报低，自建私域商业模式成为解决之道。成功私域拥有消费者规模和数据维度，C2M 定制将更为可行。

### 趋势 06：中小规模品牌大行其道

数字媒体带来消费者细分粉末化，数字化拉低准入门槛，数据赋能让精准投放成为可能。多品牌矩阵将取代单一超级品牌。

### 趋势 07：中国引领全球营销行业发展

中国消费者对数字化生活的拥抱程度远超世界其他地区。未来营销经典理论将被改写，深深刻上中国烙印。

## 五、小红书文案编辑指南

### 5.1 笔记发布全流程

#### 封面 PK 功能
- 开通视频号后可自定义封面
- 最多上传 **3 张 PK 封面**，10 小时后系统自动选择点击率最高的

#### 标题与关键词
- 标题和正文**多出现关键词**
- 封面标题 + 正文标题 + 正文描述 + 话题标签的关键词保持一致
- 关键词越精准 → 推荐越精准 → 互动率越高

#### 话题与互动
- **# 话题：** 选择关联度高 + 浏览量大的话题
- **@ 用户：** 普通账号 @ 官方薯作用不大，流量主要来自内容本身
- **投票功能：** 增加互动，了解用户想法

#### 正文写法
- 视频笔记正文不要写太长，留悬念引导观看
- 末尾植入人设介绍，给用户关注理由
- 关联商品/专栏实现带货
- 添加地点获取本地流量

#### 高级选项

| 功能 | 说明 |
|------|------|
| 发文助手 | 标明 AI/转载内容，避免被判搬运 |
| 定时发布 | 提前编辑，到时间自动发布 |
| 关联群聊 | 笔记底部显示粉丝群 |
| 品牌合作 | 入驻蒲公英平台（需 1000 粉丝） |
| 直播预告 | 用户可预约，开播收到提醒 |
| 抽奖活动 | 专业号可用（企业号每月3次，个人号每月1次） |

### 5.2 爆款标题公式

| 类型 | 示例 |
|------|------|
| **悬念与反差** | "普通人如何逆袭？"、"千万别去！" |
| **数字与痛点** | "月薪5k存下3k的极简大法" |
| **情绪共鸣** | "打工人自己的神仙食堂" |
| **标签结合** | 紧扣 #好物分享 等 |

标题控制在 **20 字以内**，可使用符号、英文、Emoji、谐音字。

### 5.3 正文排版

| 要素 | 做法 |
|------|------|
| 黄金开头 | 前 2-3 行点明核心利益 |
| 空行留白 | 多用回车分段 |
| Emoji 运用 | 充当视觉锚点（💡✨🔥） |
| 结构化 | 数字列表或小标题 |

### 5.4 流量来源

| 来源 | 策略 |
|------|------|
| 搜索流量 | 关键词优化 |
| 推荐流量 | 内容标签精准 |
| 本地流量 | 添加地点 |
| 话题流量 | 关联热门话题 |
| 粉丝流量 | 人设和互动 |

| ③ | 内容创意指令 | 多视角内容规划 |
| ④ | Emoji 添加指令 | 添加合适表情符号 |
| ⑤ | 脚本生成指令 | 口播视频讲稿 |

| ⑦ | 文章续写指令 | 基于开头续写 |
| ⑧ | 广告策划指令 | 品牌推广方案 |
| ⑨ | 文本改写指令 | 5个不同版本 |
| ⑩ | 热门问题指令 | 10个热点问题 |
| ⑪ | 素材收集指令 | 10个关键数据点 |
| ⑫ | 内容总结指令 | 精简复杂内容 |
| ⑬ | 编导/编剧指令 | 短视频剧本 |

### 示例：爆款标题指令

```
角色：你是一位美妆领域的资深小红书运营人员，
      每天负责审核和优化多篇笔记的标题。

      好的标题对笔记首页曝光起到关键作用。
      现在你需要为一篇主题为"夏季油皮持妆粉底液推荐"的内容创作标题。
要求：请创作 5 个标题，标题字数控制在 20 字以内，
      可以合理使用符号、英文、Emoji、谐音字和网络用语。
      标题要简洁有力，突出内容核心，能够激发读者点击欲望。
      请在每个标题后标注创作思路。
```
