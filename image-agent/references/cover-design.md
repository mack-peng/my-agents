# 封面设计（形式与内容）

2026-11 调研蒸馏（来源见 `output/小红书封面设计调研-2026-11-25.md`）。本文件管**形式选择与内容原则**；尺寸/导出以 `platform-specs.md` 为准，视觉风格以 `art-direction.md` 为准。

核心判断：**封面不是给已经点进来的人看的，是给还没决定点不点的人看的。** 设计感是加分项，信息差才是决定项。

## 一、形式选择（按内容选，不按喜好选）

| 形式 | 适合内容 | 关键要点 |
|---|---|---|
| 纯文字大字报 | 结论/清单/观点/干货 | 一句结论 ≤12 字，主标题占视觉权重 60%+ |
| 图文结合（真实截图+大字） | 工具/产品/教程/测评 | 截图裁局部，不做整屏照搬；大字压在留白区 |
| 高颜值单图 | 摄影/生活方式/穿搭/美食 | 画面本身即钩子，不加装饰 |
| 拼贴 / 抠图拼贴 | 合集/好物/多元素 | 同色调、主次分明，标题居中或醒目位 |
| 海报大片 | 品牌/Vlog/小众内容 | 主图 + 主标题 + 副标题 + 关键词 |
| 前后对比 | 改造/健身/美妆/效果 | 场景与角度一致，反差越大越好 |
| 系列模板 / 视频框 | 系列更新/周刊 | 固定色板、字体、角标，强化识别 |

选择逻辑：读者需要先信「这个人」→ 真人/实拍；先信「这条信息」→ 大字报；有真实产品界面 → 图文结合。**视频封面不要用抽帧**，单独做图。

## 二、内容六原则（最重要）

1. **写结果，不写分类**：写读者能得到什么、会追问什么。`155 小个子，秋天别穿这三件` ✅；`秋季穿搭分享` ❌。`你是什么体质？` ✅；`体质测评上线了` ❌。
2. **字数**：封面文案 10 字上下；主标题 3–7 字最好，大字报 ≤12 字；超过先改文案，不缩字号硬塞。
3. **封面与标题分工**：封面给结果/冲突/画面感；标题给人群/条件/数量/时间。连起来读像同一句说了两遍 → 改掉一句。
4. **每个字都要能兑现**：社区公约 2.0（2026-01）反夸张/猎奇/标题党；封面比正文狠 = 完读率掉 + 可举报，双输分发量。
5. **一个视觉中心**：主体 ≤3、文字不压主体/脸、对比够（描边或压暗底）；主色 ≤3、字体 ≤2。
6. **缩略图自检**：缩到 320px 宽，1 秒能说出「这张在承诺什么」；说不出来就重做。

## 三、制作规则

- **比例**：3:4 / 1080×1440 信息流占位最高，默认首选；1:1 用于产品图/九宫格统一；4:3 仅横构图非用不可。
- **大字报结构**：主标题（视觉权重 60%+）→ 副标题（1/3 字号、≤1 行）→ 3–5 个要点词（可选，给收藏理由）→ 角标（可选，≤12 字）。
- **留白**：标准型 40–55%，四周 ≥8%；主标题周围留空白护城河。
- **断行**：按语义断，不拆词组；两行上短下长；三行以上先压缩文案。
- **配色**：一个主色 + 一个辅色 + 一个强调色；强调色面积 ≤10%。
- **截图**：真实截图裁局部 + 大字讲解；截图本身发灰时 `contrast(1.04) saturate(1.04)` + 发丝内描边。
- **A/B**：同一文案出 2 版（问题式 vs 结果/数字式）方向对比；发布端一次可传 4 张封面 PK，10 小时后按真实 CTR 择优。

## 四、垂类要点（健康/养生）

- 标题带痛点 + 人群 + 数字/季节（`90 后女生`、`三伏天`、`3 个信号`）；封面小标题对准人群。
- 色彩鲜明、字不盖住画面主体；字太多会显著降点击。
- 该垂类爆文以视频为主，真实演示/界面增信任；「照着做就好」的方法最吃香。
- 功效类表述必须与正文一致，不做绝对化承诺。

## 五、feed-first（信息流裁切实测，2026-11 入档）

- **feed 显示窗口 ~1:1 顶部锚定裁切**：3:4 封面在 feed 里被裁到 ~1:1（1080×1440 封面可见高度 ~1080px；1440×1920 封面可见高度 ~1440px）
- **关键信息压进可见区**：主标题 / 数字 / 事实胶囊必须在 y0–1080（或 y0–1440）内；底部只放装饰或免责
- **1440 宽下文字 ≥ 90px**：feed 缩到 ~300px 时 90px ≈ 18px，勉强可读；低于 90px 直接删，不下沉到"小字区"（feed 里无小字区）
- **刊名 ≥ 120px**：系列封面必须建立栏目识别；20px 灰色 mono 在 feed 里等于不存在
- **`shoot --min-font 90` 强制**：`node image-agent/scripts/shoot.mjs <cover.html> --out <png> --min-font 90`
- **feed 1:1 预览**：`node image-agent/scripts/feed-preview.mjs <cover.png>` 出裁切预览 + 320px 缩略图

## 六、发布前自查

- [ ] 3:4，文字不贴边、不压主体/脸
- [ ] 封面文案 10 字上下，1 秒读完
- [ ] 封面给结果，标题给条件，两句不重复
- [ ] 每个字正文能兑现，无夸张/猎奇承诺
- [ ] 主色 ≤3、字体 ≤2、一个视觉中心
- [ ] 320px 缩略图仍可读
- [ ] `shoot --min-font 90` 通过（无 <90px 文字）
- [ ] `feed-preview` 生成的 1:1 裁切预览里关键信息完整
- [ ] 封面文字 ≥90px @1440 宽（feed ~300px 下可读）
- [ ] 系列封面刊名 ≥120px + 期次
- [ ] 数字来自已确认内容，无编造
