# 视觉方向与构图

目标不是“再加一个配色”，而是先决定这张图属于哪种**视觉世界**。方向定了，色板、字体、构图、图像处理才有依据。

默认深色科技只是 fallback，不是默认答案。每次做封面/分享图，先从下面 5 个方向里选 3 个给用户看，再按选定方向选模板。

## 通用铁律

1. **一个主导视觉事件**：一个被裁切的词、一个巨大数字、一张压满画面的照片、一块硬色场、一条连续图表。它占画面 35–70%，是这张图的记忆点。
2. **保护阅读区**：标题/数字/CTA 必须落在一块安静、连续的背景上。装饰、照片边缘、巨大字母、图表线不能穿过关键文字。
3. **三级信息**：主层（标题/主图/大数字）占 60–70% 视觉重量；支撑层（副标题/说明/数据）次之；元信息层（品牌/日期/来源）最小。主标题与副标题字号比 ≥ 1.8；最大与最小字号比目标 8–10 倍。
4. **最多两套字体**：标题一套、正文/元数据一套；最多 3 个字重。不要用 4 种字体制造层级。
5. **一个强调色**：面积控制在 10–25%；同一张图不出现第二个强调色。用透明度/明度做层级，不要靠加新颜色。
6. **网格是脚手架**：12 栏 + 8px 基线；允许一个元素突破网格、贴边、裁切或跨栏。全部元素对齐网格反而像网页后台。
7. **不要默认卡片**：三张并排卡、圆角容器、图标+标题+描述重复，是最明显的模板感。优先用对齐、留白、分隔线、层级来组织。
8. **不要默认居中**：居中标题 + 副标题 + 三张卡 + 底部按钮，是最典型的 AI 模板。至少让主轴偏置、让主视觉压边、让文字与图像形成张力。
9. **图片有角色**：主体 / 地点 / 证据 / 氛围 / 纹理。没有角色的图不要放。禁止把图当壁纸再压一段字。
10. **文字、数字、Logo、UI 永远 HTML**：AI 只出摄影/插画/纹理素材；不让 AI 画中文标题、Logo、真实界面、图表。

## 方向 1：Swiss editorial / 大字海报

适合：周刊封面、观点文、知识总结、报告、榜单、活动。

- **色板**：纸白 `#F4F1EA` 或墨黑 `#0C0A09`；文字 `#141414` / `#FAF9F5`；一个强调色（Swiss red `#C8102E`、cobalt `#003B8E`、lime `#D7FF3F` 三选一）；分隔线用同色 10–14% 透明度。
- **字体**：标题用系统无衬线粗体（PingFang SC Semibold/Heavy）或窄体；元数据用 Maple Mono / SF Mono；标题行高 `0.85–1.0`，字距 `-0.04em` 到 `-0.06em`。
- **构图**：一个被裁切的大词/大数字/照片块压住画面 35–70%；12 栏网格，元素可以跨栏或贴边；2–4 组 11–14px 微排版（日期、编号、来源、坐标）；一块硬色场或反白区作为阅读区。
- **主视觉事件**：裁切词、巨大日期/数字、硬分割场、几何环/条、双色照片。
- **AI/摄影**：通常不用 AI；需要照片时用双色调/高反差/裁切，不做圆角图卡。
- **模板**：`templates/editorial-poster.html`。背景大词改 `--ghost: "..."`，必须是主题相关词。
- **避免**：居中堆叠、圆角卡片、芯片标签一排、每个元素都加底色、标题不够大。

## 方向 2：Photo-led cinematic

适合：人物、城市、产品场景、活动、生活方式、需要真实感的封面。

- **色板**：照片本身 + 黑/深灰 scrim；文字 `#F7F5F0`；一个强调色只用于关键词/数字/细线。
- **字体**：标题用无衬线粗体或窄体，2–3 行；元数据用等宽；标题压在照片下 1/3，不要压脸/产品主体。
- **构图**：满版照片；主体在左/右 1/3，另一侧留出低细节区放标题；底部 25–35% 渐变 scrim；顶部一行 kicker；最多 1 个数据点。
- **主视觉事件**：照片本身。照片必须有明确主体、光线、景深和留白，不是抽象纹理。
- **AI/摄影**：优先 Unsplash 真实摄影；需要 AI 时写清主体、环境、镜头、光线、色板、留白位置，并加 `no text, no letters, no watermark, no logo, no UI`。禁止只写 `abstract dark tech background`。
- **模板**：`templates/photo-cover.html`（深色）或 `templates/photo-cover-light.html`（纸白亮色）。`.photo` 是占位，交付前必须换成真实照片/AI 图。
- **避免**：文字压脸、满版杂乱、低清放大、假产品图、AI 乱码字。

## 方向 3：Data / infographic

适合：报告、榜单、指标、对比、行业分析、数据型周刊。

- **色板**：纸白/墨黑 + 一个数据强调色；网格线/轴用 10–14% 透明度；最多 3 个语义色（主体/对比/警示）。
- **字体**：一个巨大数字/指标做主角；标签和来源用等宽；标题比数字小，但仍要能第一眼读到。
- **构图**：一个连续图表/山脉/矩阵/坐标系统贯穿画面；数字站在图形上；每个数字有自己的刻度；不要三张并排卡 + 三个小图。
- **主视觉事件**：巨大数字、连续图表、矩阵、时间轴。
- **AI/摄影**：不用 AI 画图表；AI 只可做极淡的纸纹/纹理。
- **模板**：`templates/data-story.html`（默认横向 1600×900；竖版封面要重排成单列，不要直接缩放）。
- **避免**：编数据、装饰性折线、无刻度对比、假图表、把数字塞进圆角卡片。

## 方向 4：Warm humanist / 纸张人文

适合：生活方式、访谈、品牌故事、文化、教育、社群。

- **色板**：暖白 `#F5F1E8`、墨 `#2B2723`、次要 `#7A7268`、一个低饱和强调（赭石 `#B45A3C`、金 `#C9A962`、橄榄 `#6B7A4F`）。
- **字体**：标题用衬线（Songti SC / Noto Serif SC），正文用系统无衬线；标题行高 `1.05–1.15`，正文 `1.6–1.75`；元数据用等宽小字。
- **构图**：非对称两栏或上方大标题 + 下方小图；大量留白；一条细线/一个小色块；不要满版装饰。
- **主视觉事件**：一个安静的大标题、一个真实的小图、一个手写/纸张质感细节。
- **AI/摄影**：自然光、真实材质、胶片颗粒、低饱和；描述具体场景，不写“温暖高级感”这种空词。
- **模板**：`templates/warm-paper.html`。`.figure` 是占位，交付前换成真实小图或纸张纹理。
- **避免**：假复古、纸张纹理叠太多、全篇衬线、低对比灰字。

## 方向 5：Brutalist typographic

适合：强观点、宣言、活动、青年文化、争议话题。

- **色板**：黑/白 + 一个高饱和强调；硬色块，不用渐变。
- **字体**：超大字重、窄体/压缩体；字体本身就是主视觉；可以裁切、重叠、旋转，但关键文字必须完整可读。
- **构图**：文字占 40–70%；边缘裁切；斜线/色块/重复字；微排版只放真实信息；无图片或只放一张高反差图。
- **主视觉事件**：巨大单词/数字、硬色块、重复字。
- **AI/摄影**：通常不用；需要图片时高反差、单色、裁切。
- **模板**：`templates/type-poster.html`。
- **避免**：不可读的堆叠、全大写长正文、多个强调色、为了“酷”而酷。

## 方向选择规则

- 有真实数据/对比 → **Data**，不要用人物图硬撑。
- 有人物/地点/产品实景 → **Photo-led**，优先真实摄影。
- 观点/周刊/知识/榜单 → **Swiss editorial**。
- 生活方式/访谈/文化 → **Warm humanist**。
- 强观点/活动/宣言 → **Brutalist**。
- 没有明确倾向时：给 Swiss editorial、Photo-led、Data 三个方向，不要默认深色科技。

## AI 背景的额外约束

- 封面背景默认**不再生成 abstract dark tech texture**。
- 需要背景时，二选一：
  1. 有明确主体/场景的照片或 AI 图（人物、空间、产品、城市、自然）；
  2. 纯 HTML/SVG 图形系统（网格、色块、线条、图表、渐变）。
- AI prompt 必须写：主体、环境、构图/留白、光线方向、色板、材质、镜头/媒介、`no text, no letters, no watermark, no logo, no UI`。
- 一次只改一个变量；固定 seed；记录 model / prompt / negative / seed / task_id / 输出路径。

## 安全区

平台尺寸与安全区以 `references/platform-specs.md` 为准。通用规则：

- 小红书：底部 12% 不放关键文字；标题在上 2/3；缩略图可读。
- 公众号：底部 28% 是标题覆盖区；核心内容在上 60–65%。
- 小程序分享：核心内容在中央 1:1；底部 8% 不放关键文字。
- 所有平台：文字离边 ≥ 画布宽度的 6%；装饰可以出血，但必须标 `data-bleed`。

## 反模式速查

- 居中标题 + 三张圆角卡 + 底部按钮。
- 紫色/荧光绿渐变当“科技感”。
- 每个元素都套卡片、每个标题都有 eyebrow。
- 4 种字体、3 个强调色、5 种阴影。
- 巨大的“AI 生成感”抽象背景，没有主体。
- 低清图放大、AI 画中文/Logo/UI。
- 只换颜色不换构图，叫“新方向”。
