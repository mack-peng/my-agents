# 设计评审（看图之后，交付之前）

`shoot.mjs` 只证明“技术上没坏”，不证明“好看”。本清单在自动 QA 之后执行；不通过的项先修，再给用户看。

## 执行方式

1. `Read` 最终 PNG 全尺寸。
2. `sips -Z 320` 生成缩略图，再 `Read` 缩略图。
3. 按下面 12 项逐条打分（1–5）。
4. 任何一项 ≤ 2 分：必须重做/换方向；3 分：修到 4 分再展示；4–5 分：通过。
5. 至少做一次“删掉一个装饰元素”的减法测试，并记录删了什么、为什么更好。

## 12 项评分

| # | 维度 | 4–5 分的标准 | 低分信号 |
|---|---|---|---|
| 1 | 一句话概念 | 能用一句话说清这张图只讲什么；所有元素服务这句话 | 什么都想讲，信息平铺 |
| 2 | 主视觉事件 | 有一个占 35–70% 的主导事件（大字/大数/照片/图表/色块） | 均匀铺满，没有记忆点 |
| 3 | 阅读路径 | 3 秒内先看到标题，再看到支撑信息，最后看到元数据 | 第一眼不知道看哪 |
| 4 | 字号对比 | 最大/最小字号 ≥ 8×；主标题与副标题 ≥ 1.8× | 所有字差不多大 |
| 5 | 字体 | ≤ 2 套字体、≤ 3 个字重；标题/正文/元数据角色清晰 | 4 种以上字体/字重乱用 |
| 6 | 颜色 | 一个背景 + 一个文字色 + 一个强调色；强调色面积 10–25% | 多强调色、渐变滥用、灰字低对比 |
| 7 | 构图 | 有明确轴线/偏置/裁切/张力；不是居中堆叠 | 居中标题 + 三张卡 + 底部按钮 |
| 8 | 留白 | 留白有节奏，主次之间有呼吸；不是均匀 padding | 全图同一种间距，挤或空 |
| 9 | 图像 | 图片有角色（主体/地点/证据/氛围）；不是壁纸 | 随便一张图压字；AI 乱码/假 Logo |
| 10 | 内容真实性 | 每个数字/引用可回溯；没有编造 | 数据无来源、假客户、假截图 |
| 11 | 缩略图 | 320px 宽仍能读出主标题/主数字；主体可辨 | 小图糊成一团、标题看不清 |
| 12 | 贴题度 | 把品牌名换成竞品，图不成立；只属于这个主题 | 换成任何公司都成立 |

## 减法测试

对每个可疑元素问：

1. 它是什么？（具体命名：chip、eyebrow、光晕、嵌套卡片、装饰线、重复图标…）
2. 它承担什么信息/层级/品牌作用？
3. 删掉后，信息、层级、品牌感是否仍然成立，而且更清楚？
4. 如果是 → 删；如果否 → 用现有系统做最小修正，不要加新效果补偿。

## 三个快速测试

- **眯眼测试**：眯眼后还能看到主标题和主视觉吗？
- **灰度测试**：去色后层级还成立吗？只靠颜色区分就重做。
- **替换测试**：把主题/品牌换成竞品，图还成立吗？成立说明不够贴题。

## Prompt 评审（AI 图专用）

- [ ] 写清了主体、环境、构图/留白、光线方向、色板、材质、媒介/镜头。
- [ ] 没有 `4k, masterpiece, ultra detailed, award-winning` 这类空词堆砌。
- [ ] 没有要求 AI 画中文标题、Logo、真实 UI、图表。
- [ ] 有 `no text, no letters, no watermark, no logo, no UI`。
- [ ] 模型选择正确：最终稿 `qwen-image-3.0` / `wan2.7-image` / 即梦 Seedream，不用 `z-image-turbo` 做最终主视觉。
- [ ] 需要风格一致时有参考图，或用图生图，不只靠文字描述。
- [ ] 记录了 model / prompt / negative / seed / task_id / 输出路径。
- [ ] 默认 2 张候选；一次只改一个变量。

## 常见反模式（发现即扣分）

- 居中标题 + 三张并排卡 + 底部按钮。
- 每个段落都套圆角卡片；卡片里再套卡片。
- 每个标题上都有 tracked uppercase eyebrow。
- 紫色/青色/荧光绿渐变当“科技感”。
- 巨大抽象光晕/网格背景，没有主体。
- 一个强调色不够，再加第二个、第三个。
- 标题用渐变文字、低对比灰字、超小正文。
- 为了“高级”加玻璃、模糊、光晕、噪点、阴影五件套。
- 把 1440 设计直接缩成 900/810，不重排版。
- 只换色板不换构图，叫“新方向”。
