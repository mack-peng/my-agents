# 交付前检查清单

不看图不算完成；`shoot` 不报错也不等于图能用。按顺序过。

## 1. 渲染前

- [ ] brief 已确认：用途、平台、尺寸、受众、必须出现的字、禁用元素。
- [ ] 所有数字/事实能指出来源；没有编造。
- [ ] 文案已定稿（标题断行、副标题、数据、标签）。
- [ ] 素材已本地化到 `output/<slug>/assets/`；没有依赖外链。
- [ ] 字体可用：`document.fonts.check()` 通过，或已接受系统字体兜底。
- [ ] 画布尺寸与平台预设一致；`<meta name="viewport">` 已同步。
- [ ] AI/摄影图已下载并检查分辨率 ≥ 展示尺寸的 1.2 倍。
- [ ] Unsplash 素材有 `<id>.json` sidecar；`recipe.md` 记录 Photo ID、摄影师、原图页；发布署名保留。
- [ ] Unsplash 搜索词不含内部/敏感信息；内部/敏感图片未发给 AI 服务商。

## 2. 渲染

```bash
node image-agent/scripts/shoot.mjs output/<slug>/still.html \
  --out output/<slug>/<name>.png --json
```

- [ ] 退出码 0；JSON 无硬错误。
- [ ] 字体失败：0。
- [ ] 图片缺失/破图：0。
- [ ] 文字被裁切：0。
- [ ] 元素溢出画幅：0（除 `data-bleed` 装饰层）。
- [ ] 页面滚动：0。
- [ ] 控制台/页面报错：0。
- [ ] 图片低清警告：已处理或接受。
- [ ] `sips -g pixelWidth -g pixelHeight` 与目标尺寸完全一致。

## 3. 视觉

**全尺寸看图**（`Read` 最终 PNG）：

- [ ] 主标题第一眼可读；层级清楚。
- [ ] 主视觉焦点明确；没有被裁掉。
- [ ] 文字没有压住人脸、产品主体、Logo、二维码。
- [ ] 对比度足够；暗底浅字/亮底深字。
- [ ] 边缘无意外裁切、无溢出、无滚动条。
- [ ] 留白节奏舒服；不挤、不空。
- [ ] 色彩统一；强调色不超过 10% 面积。
- [ ] 中文断行自然；没有孤字/孤行。
- [ ] Logo 原样、清晰、有足够留白；没有被 AI 重画。
- [ ] 数字与来源一致；单位/日期/版本号正确。
- [ ] 没有 AI 痕迹：多余手指、错字、乱码、拼接缝、塑料皮肤、假 Logo。
- [ ] 整张图"只能属于这个主题"；换成竞品不成立。

**缩略图测试**：

```bash
sips -Z 320 output/<slug>/<name>.png --out tmp/thumb.png
```

- [ ] 320px 宽仍能读出主标题。
- [ ] 主体仍可辨；没有糊成一团。
- [ ] 关键信息没有被平台 UI 覆盖。

**灰度测试**：

- [ ] 去色后层级仍成立；不是只靠颜色区分。

## 4. 平台专项

### 小红书 1440×1920

- [ ] 底部 12% 没有关键文字。
- [ ] 主标题在上 2/3。
- [ ] feed 缩略图可读。
- [ ] 3:4 裁切后主体完整。

### 小程序分享 1280×1024

- [ ] 中央 1:1 裁切后标题/Logo/主视觉仍完整。
- [ ] 四周 6–8% 页边距。
- [ ] 底部 8% 没有关键文字。

### 小程序广告 810×1080

- [ ] 底部 10% 没有关键文字/CTA。
- [ ] 重要内容在上 80%。
- [ ] 小尺寸下 CTA/按钮可辨。

### 公众号 900×383

- [ ] 底部 28% 没有关键文字/人脸/核心视觉。
- [ ] 重要内容在上 60–65%。
- [ ] 标题不超过两行；字号 48–72px。
- [ ] 顶部 8% 没有关键信息。

### OG / 分享卡

- [ ] 1200×630 或指定尺寸准确。
- [ ] 中央 80% 放关键内容。
- [ ] JPG < 1MB（如平台要求）。
- [ ] 在社交预览小图里标题可读。

## 5. 文件与交付

- [ ] 文件名符合 `{用途}-{平台}-{宽x高}.{png|jpg}`。
- [ ] 成品在 `output/<slug>/`；没有写 Desktop/Downloads。
- [ ] `input/` 原图未被修改/覆盖/删除。
- [ ] `assets/` 只保留最终用到的素材；中间产物已清理。
- [ ] `recipe.md` 完整：brief、文案、数据来源、AI receipt、色板、字体、QA、下次改哪里。
- [ ] 多版本在 `archive/`；最终文件不被历史版本覆盖。
- [ ] 如交付文案：标题/正文/标签与图片一致；数字一致。
- [ ] 没有把 API key、AK/SK、内部链接写进文件或对话。

## 6. 常见反模式

- ❌ 用通用模板套任何公司。
- ❌ 让 AI 画中文标题/Logo/真实 UI。
- ❌ 编数字、编引用、编客户。
- ❌ 只看小图不看全尺寸；或只看全尺寸不看缩略图。
- ❌ 把一个尺寸的设计直接缩放成另一个比例。
- ❌ 用低清图放大充数。
- ❌ 文字压在平台 UI 覆盖区。
- ❌ 交付前没跑 `shoot` / 没看图。
- ❌ 未经确认批量生成/4K/多图，导致费用失控。
