# 做分享图

适用：小程序分享卡、OG / 社交分享卡、朋友圈、社群海报、公众号分享卡。
原则：**小尺寸可读、一个钩子、品牌清楚、适配平台安全区**。

## Step 0 采集

- **平台 / 尺寸**：
  - 小程序分享：1280×1024
  - OG / 通用分享：1200×630
  - 朋友圈：1080×1350（或 1080×1080）
  - 公众号分享卡：500×500
  - 用户给精确像素时以用户为准。
- **分享场景**：群聊/朋友圈/公众号/官网 OG/小程序卡片；是否会被裁成方形。
- **一句话钩子**：主标题；副标题可选；最多 3 个要点。
- **品牌**：Logo、品牌名、官网/小程序名；有二维码就提供 PNG（不自己生成二维码）。
- **受众**：他们为什么要点开/转发。
- **模式**：分享图默认**手工 HTML**；需要照片/插画时用 AI 背景，文字仍 HTML。

## Step 1 设计规则

- **一个钩子**：主标题只讲一件事；不要塞 5 个卖点。
- **小尺寸优先**：按 320px 宽预览；标题仍需可读。
- **层级**：主标题 > 副标题/一句话 > Logo/二维码。
- **安全区**：
  - 小程序分享：中央 1:1 安全区；四周 6–8%。
  - OG：中央 80%；边缘不放关键文字。
  - 朋友圈：底部 10% 避开 UI。
- **对比**：小图容易糊；深底浅字或浅底深字，避免低对比渐变。
- **Logo**：原始 SVG/PNG；留白 ≥ 高度 0.5 倍；不重绘。
- **二维码**：用户提供原图；保持足够大（建议 ≥ 120px 展示尺寸）和静区；不压缩变形。

## Step 2 方向 sign-off

给 1–2 个方向即可（分享图不需要 3 个复杂方向）：

- 纯文字卡（最快、最稳）
- 图像 + 文字（需要背景/人物/产品）
- 数据/清单卡（3 个要点）

确认后制作。

## Step 3 制作

1. 建工程：`mkdir -p output/<slug>/assets/{ai,brand,refs}`。
2. 需要背景图 → `bl image generate` / `ve-image.mjs`；提示词留出文字区，`no text`。
3. 以 `templates/still.html` 为骨架，改尺寸/色板/文案；分享图通常更简洁，删掉不必要的装饰。
4. 渲染：

```bash
node image-agent/scripts/shoot.mjs output/<slug>/<name>.html \
  --out output/<slug>/<name>.png --json
```

5. OG 可同时出 JPG：

```bash
node image-agent/scripts/shoot.mjs output/<slug>/og.html \
  --out output/<slug>/share-og-1200x630.jpg \
  --format jpg --quality 88 --json
```

6. 检查：
   - `sips -g pixelWidth -g pixelHeight` 尺寸准确。
   - 320px 缩略图可读。
   - 中央 1:1 / 中央 80% 裁切后仍成立。
   - OG 文件 < 1MB（如平台要求）。
   - Logo/二维码未变形、未被裁。

## Step 4 交付

- 最终 PNG/JPG。
- `recipe.md`。
- 分享文案：一句转发语 + 标题；如用户需要，给 2–3 个版本。
- 多尺寸时给 contact sheet 或并排预览。

## 分享图速查

| 场景 | 尺寸 | 重点 |
|---|---|---|
| 小程序分享卡 | 1280×1024 | 中央 1:1 安全区；标题+Logo |
| OG / 社交卡 | 1200×630 | 中央 80%；JPG < 1MB |
| 朋友圈 | 1080×1350 | 一个钩子；底部 10% 避开 UI |
| 公众号分享卡 | 500×500 | 字少、对比强、Logo 清楚 |
| 社群海报 | 1080×1440 或指定 | 标题+时间/地点+二维码 |

## 反模式

- ❌ 把封面图直接缩成分享图（比例和安全区都变了）。
- ❌ 小图塞长标题/多段正文。
- ❌ 二维码太小、变形、没有静区。
- ❌ 让 AI 画 Logo/二维码/中文。
- ❌ 低对比渐变导致小图看不清。
- ❌ OG 文件过大。
