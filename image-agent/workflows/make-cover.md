# 做封面图

适用：小红书封面、小程序封面/广告图、公众号文章图、视频封面、活动海报。
原则：**一次采集齐 → 内容核对 → 方向 sign-off → 制作 → 看图迭代 → 交付**。

## Step 0 采集（一次问齐，不挤牙膏）

- **平台 / 尺寸**：默认按 `references/platform-specs.md`：
  - 小红书：1440×1920
  - 小程序分享：1280×1024
  - 小程序广告：810×1080
  - 公众号文章图：900×383
  - 视频封面：1920×1080 / 1080×1920
  - 用户给精确像素时以用户为准。
- **主题与目标**：一句话主题 + 读者看完要记住什么。
- **文案**：主标题（精确到字）、副标题、3–5 个要点/数字、标签/CTA。
- **素材**：Logo、产品截图、人物/场景图、数据来源、字体。放根 `input/`，说明哪些必须用。
- **风格**：参考图/链接，或从默认视觉语言/风格库选；没有就按默认深色科技编辑感。
- **模式**：手工 / 混合 / AI。封面默认**混合**（AI 背景 + HTML 文字）。
- **变体数**：默认 1 张；需要对比时 2–3 个方向。
- **硬约束**：必须出现的字、禁用元素、截止时间、是否可外发。

用户未提供的项用默认值继续（不阻塞），并在方案里标明默认假设。

## Step 1 内容与事实

- 每个数字/引用对来源；不确定的删掉或标缺口。
- 标题优先短：小红书 ≤ 15 字/行，公众号 ≤ 20 字；长标题先改文案，不靠缩小字号硬塞。
- 数据卡只放 1–3 个确认过的数字；不要为了版面编数字。
- 涉及内部/未公开信息 → 不用 AI，纯手工排版；除非用户确认可外发。

## Step 2 设计方向（闸门 2）

给 2–3 个方向，每个写清：

- 概念一句话（为什么贴这个主题）
- 色板（背景/主文字/强调色）
- 字体（标题/元数据）
- 构图（左对齐/居中/满版/数据卡/拼贴）
- 图像处理（AI 背景/摄影/纯色/纸张）
- 推荐理由

等用户选一个再动手。没选就按推荐方向做一版，并注明"可换方向"。

## Step 3 制作

1. 建工程：

```bash
mkdir -p output/<slug>/assets/{ai,brand,fonts,refs}
cp input/<需要的素材> output/<slug>/assets/...
```

2. （可选）生成背景/插画：

```bash
bl image generate --prompt "<prompt with negative space, no text>" \
  --model z-image-turbo --size 3:4 --n 1 --watermark false \
  --out-dir output/<slug>/assets/ai/
```

或火山：

```bash
node image-agent/scripts/ve-image.mjs t2i \
  --prompt "<prompt>" --size 1536x2048 \
  --out output/<slug>/assets/ai/bg.png
```

3. 写 HTML：以 `templates/still.html` 为骨架复制到 `output/<slug>/<name>.html`，改：
   - `--w` / `--h` 与 `<meta name="viewport">` 为目标尺寸。
   - `:root` 色板/字体。
   - 文案、断行、数据。
   - 背景图路径 `assets/ai/bg.png`；Logo `assets/brand/...`。
   - 安全区按 `references/platform-specs.md`。
   - 装饰层出血加 `data-bleed`。

4. 渲染：

```bash
node image-agent/scripts/shoot.mjs output/<slug>/<name>.html \
  --out output/<slug>/<name>.png --json
```

5. 按 JSON 修：字体失败、图片缺失/低清、文字裁切、溢出、控制台错误。修完重跑。

6. **看图**：`Read` 最终 PNG 全尺寸；再 `sips -Z 320` 看缩略图。按 `references/qa-checklist.md` 过一遍。

## Step 4 初稿 sign-off（闸门 3）

展示：

- 成品 PNG
- 一句话设计说明（为什么这样排）
- 每个数字的来源
- 可改点（标题/数据/颜色/背景）
- 默认假设

问："初稿完成，请确认（OK 继续 / 指出要改的）"。

## Step 5 交付

- 最终 PNG/JPG（按平台命名）。
- `recipe.md`（用 `templates/recipe.md`）。
- 可选发布文案：标题（≤20 字）、5 个要点、5–6 个标签；数字与图片一致。
- 多版本放 `archive/`；不覆盖用户输入。
- 交付说明写清：哪些字/数字在 HTML 里可直接改、下次怎么复用。

## 封面类型速查

| 类型 | 尺寸 | 关键约束 |
|---|---|---|
| 小红书 | 1440×1920 | 底部 12% 避开 UI；标题上 2/3；缩略图可读 |
| 小程序分享 | 1280×1024 | 中央 1:1 安全区；四周 6–8% |
| 小程序广告 | 810×1080 | 底部 10% 留给平台标签；重要内容上 80% |
| 公众号文章图 | 900×383 | **底部 28% 是标题覆盖区**；核心视觉上 60–65% |
| 视频封面横 | 1920×1080 | 右下角避开时长/播放按钮 |
| 视频封面竖 | 1080×1920 | 底部 15% 避开标题/按钮 |

## 反模式

- ❌ 用可套任何公司的通用模板。
- ❌ 让 AI 画中文标题、Logo、真实 UI。
- ❌ 编数字/引用；用未确认的内部数据。
- ❌ 未 sign-off 就做 3 个方向 × 多尺寸。
- ❌ 只跑 `shoot` 不看图。
- ❌ 把一个尺寸直接缩放成另一个比例。
- ❌ 自动导出到 Desktop/Downloads。
