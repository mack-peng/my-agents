# Cover Phase 2: 设计方向（闸门 2）

先读 `references/cover-design.md`（必做）——按内容类型选形式，**feed-first 先行**：
1440 宽下文字 ≥90px、刊名 ≥120px + 期次、关键信息压进 1:1 可见区；**封面只放大字，小字下沉正文**。

## 三个方向（带推荐）

按 `references/art-direction.md` 的 5 个方向，给 3 个候选，每个写清：

- 方向名 / lineage
- 概念一句话
- 色板（背景 / 主文字 / 强调）
- 字体（标题 / 正文 / 元数据）
- 构图（主视觉位置 / 网格 / 留白）
- 主导视觉事件
- AI/摄影/纯色/纸张
- 对应模板
- 反模式
- 推荐理由

**不要没选就默认做深色科技版**。用户说「你定」时才按推荐方向做，并注明可换。

## 方向消息形状

```
3 个方向（推荐 A）
A <方向名>：<一句话概念> / 色板 / 主视觉事件
B <方向名>：...
C <方向名>：...
选 A/B/C，或「你定」
```

## 闸门 2 · Sign-off

用户选 → 进 Phase 3（制作）。**没有选定不动手**。

## 被调用时的行为

- brief 的 `visual_direction` 非空 → 直接用，不问
- brief 的 `visual_direction` 为空 → 按内容类型默认（数据/资讯 → Swiss editorial/Data；有真实主体 → Photo-led），在 brief 确认消息中标注为假设，不单独再问
- 用户要求多变体（mode: full）→ 本阶段给 3 个方向，Phase 3 每方向各出 1 稿做 A/B
