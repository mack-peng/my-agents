# ⑤ 竞品监测（同类小工具横向对比）

进入条件：同品类（小游戏 / 面部修图 / 拼图 / 记忆力类）的小工具，用户想「看看同行怎么做」。xhs-agent 只出报告，抓取与页面读取全部委托。

## 输入

- 品类关键词（如「全屏小游戏」「面部对比」「4399 风格」）
- 抓取范围 = 小红书内部做法：**无法直接爬小红书 feed 内容的数据不抓**，仅监测：
  - 创服平台同类小工具**公开发布页 / 前端**信息的间接来源（应用官方项目博客、报告）
  - 站外类似 H5 / 小游戏（3455 拼图站、小游戏聚合页）的推广页面

## 展开

1. 委托 `use firecrawl-agent` search 站外同类]**玩法汇总页 / 评测文 / 聚合页**的 1–3 条可用资料 → 抽 URL + 摘要
2. 汇总每条竞品 publish 姿态的**共性**：推广标题怎么写、what they offer、有无插旗/分享卡
3. 与本工具（workflow ①/⑥ 产物 + workflow ③ 文案）对比；不抓内部密 / 无来源的事实
4. 按维度评比：

| 品类维度 | 本工具 | 竞品共性 |
| --- | --- |
| 主题 | |
| 互动 hook | |
| 有无战绩卡 | |
| 上够钩子 | |

5. 建议出「可复用亮点」3 条 + 「本工具 TODO」2 条，只出报告

## Hard Stop

- 不抓小红书内部 / 登录态数据（合规边界）
- 不自动进入竞品小工具进行测试（体验对比需要用户自己真机运行）
- 落 `output/{YYYY-MM-DD}-{slug}-competitor.md`
