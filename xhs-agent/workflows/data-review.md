# ④ 数据回流（后台指标复盘）

进入条件：已完成上线，用户拿到创服平台后台或自己的 XHS 笔记数据，要「复盘 / 数据分析 / 怎么优化」。xhs-agent **只做分析，不抓 Excel / 不自动登录平台后台拉数据**。

## 输入

用户贴的数字 / 截图（人工或 OCR 导出均可），最常见字段预期：

- 小工具的 访问次数 / 打开人数 / 完局人数 / 次日留存
- 对应推广笔记的 阅读 / 点赞 / 评论区回流

## 计算与判断

```text
完局率     = 完局人数 / 打开人数
留存率     = 次日访问人数 / 当日打开人数
笔记转化率 = 从笔记点开 / 笔记阅读
```

- 概念先贴数例再解读，不编阈值（绝对说"80% 算好"是无来源的编造）
- 每个指标给出「与上一周期对比」或「绝对值 + 读者的已知基线由用户补充」

## 输出

一张 ≤5 列的表 + 2–4 条结论性建议 + 建议 improvement 只出**设计**，不改产品本身（改产品走 use develop-agent / code-agent）：

| 指标 | 本次 | 上次 | 读法 |
| --- | --- | --- | --- |

- 结论用交叉证据（例如「完局率高 + 留存率低 → 目录短期好玩但难度断崖陡」，用难度梯度数据验证）
- 明确下一步建议走哪条 workflow（改文案走 ③、新版本走 ① 迭代）

## Hard Stop

- 不编数据；用户缺哪个维度就标「缺口」继续出其他部分
- 不主动登录平台抓数
- 报告落 `output/{YYYY-MM-DD}-{slug}-data-review.md`
