# XHS 推广笔记文案骨架

> 产出推广笔记标题与正文时的核对表与模板。发过一条真实成功的推广内容后，本页只记录可复用骨架；不做模板化套用。

## 字数与安全约束

- 标题 ≤ 20 字（创服平台上架简介 ≤ 14，是另一件事，勿混）
- 正文不设硬上限，但 XHS 风格应 ≤ 300 字、段落 < 10 行/段
- 违禁词：不承诺「最强 / 第一 / 绝对通关 / 0 广告」，不编数据
- 数字引用来源：只允许
  1. 用户当轮确认的真实战绩（如「30 秒通关普通」）
  2. 项目常量（`~/Projects/minesweeper/src/constants/sweep.js` 四种难度）
  3. CLI 回执里的实际 appId / 版本 / 审核状态
- 无来源的数字删除或用占位 `{用户补充}`，交付时让用户替换

## 使用流程

1. 问用户这一条笔记的目的（常规种草 / 拉挑战 / 更新公告），选标题角度
2. 基于骨架 A/B 起草，数字必须来自用户确认或项目常量
3. 拿生成的笔记标题 + 正文 + 配图（image-agent 产出）三件一起给用户核字数与错别字
4. 交付时提示：正文里的占比是编辑视图的实际字数；可以直接复制发小红书 App
