# 小红书小工具创服平台上架表单（实测记录 2026-11-06）

> 来源：创服平台手动上传页实测填写。平台可能更新，以实际后台为准。

## 表单字段

| 字段 | 约束 | 说明 |
|---|---|---|
| 小工具名称 | ≤ 14 字 | 已实测「扫雷」2/14；推荐直接用产品名 |
| 简介 | ≤ 14 字 | 已实测可提交 9 字如「经典扫雷，一局上头」 |
| 图标 | PNG/JPG/JPEG ≤ 5MB，推荐 1:1 | 平台小图展示；1024×1024 足够 |
| 封面 | JPG/JPEG/PNG ≤ 10MB，**固定裁剪 3:4** | 平台后台强制裁为 3:4，务必直接按 3:4 设计 |

## 上传流程（三步）

1. 表单填名称/简介 + 上传图标与封面 → 提交
2. 上传 zip 静态包 → 平台模拟器验证
3. Android 真机扫码 → iOS 真机扫码 → 审核

## 已知实测经验

- 图标 / 封面均用 HTML 渲染（见 `use image-agent`），尺寸精确到像素，无裁切损耗。
- 封面 1440×1920 = 3:4，文件 ≤1.5MB，远低于 10MB 上限。
- 上架后未发现审核问题；简介 9 字为可提交长度。
